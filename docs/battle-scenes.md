# 主线关卡场景表（草案）

给主线三幕九章的每一场战斗配上场景，并写好关卡选择和布阵界面上显示的场景描述。章节和剧情以 [story.md](story.md) 第 3 节为准，场景的环境效果和地块以 [game-design.md](game-design.md) 第 5.5 节（战斗场景与地形）和 `terrains.json` 为准。这里只排“哪一关在哪儿打、地上有什么、怎么介绍给玩家”，不改任何数值。

## 1. 怎么排

**每章一个主场景，路上换几次景。** 设计文档 5.5 定的是“每章一种主场景”。实际排关时，一章十关大约 6~7 关用主场景，另外 3~4 关是行军路上经过的地方（河谷、绿洲、温室、湖畔森林），用其他已经出现过的环境。这样一章里既有统一的气氛，又不会十关看起来一样，玩家也能在不同环境之间换阵容。内核已经支持每关单独写 `terrain`，不需要改代码。

**几条规则**

- 每种环境第一次出现的那一关（表里标 ★新）用手绘布局、敌人偏弱，让玩家先看清这种环境的效果。
- 章末 Boss 关、剧情关和新环境首关用手绘 `layout`，其余关只写 `layoutSeed`（缺省按关卡 id 算，同一关每次进来地形一样）。
- 地块写的是这一关想突出的那一两种。用种子生成的关，地块数量在 `terrains.json` 里该环境的范围内；手绘的关可以放环境默认不带的地块（例如在草原上画灌木），表里会注明。
- 一个环境只用在故事里说得通的地方：亡灵的地盘才有骨堆，法师塔才有法力泉，枯竭区只出现在被亡灵吸干的地方。
- 精英关（每章 3 个）挑本章打过的场景，布局全部手绘，地块比普通关多一些、更刁钻。

**环境一览**（✓ 已在内核实现，其余等地形第三期）

| `forest` ✓ | 古木森林 | 森林 | 2 | 4、6、7、8 |

## 5. 写进配置表的方式

关卡配置还没有单独的表，现在的战斗配置在 `encounters.json`。主线关卡表做出来时，每关加三项场景字段，地形的 `terrain`、`layout`、`layoutSeed` 沿用内核已支持的写法：

```json
{
  "id": "ch1_03",
  "name": "磨坊小河",
  "terrain": "plains",
  "layout": { "player": ["..."], "enemy": ["..."] },
  "sceneText": "老磨坊的水车早就停了，小河漫过了石桥。蹚水的部队会慢下来；立在水边的法力水晶，连线却能多伸出一格。"
}
```

- 关卡编号 `1-3` 在配置里写成 `ch1_03`，精英关写成 `ch1_e1`。
- `sceneText` 在关卡选择和布阵界面显示；环境的那段介绍写在 `Localization/Game.csv` 的 `terrain.<id>.description`（第 2 节的文案可以直接替换现在的短描述）。
- 文本接入多语言表后，`sceneText` 换成文本 key（如 `stage.ch1_03.scene`）。
