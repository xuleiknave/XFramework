# 故事背景与角色关系

> v4.0（决策 68）：题材从西幻“魔网”改为“星宿国潮”。主线结构（五根线、永夜、断线日、阿织的倒计时、三幕九章、结局五步）和 v3.0 一样，换的是世界、人名、地名和造型。新旧名称对照见 [game-design.md](game-design.md) 附录，v3.0 原文见 git 历史。名字都是草案。

主线故事把五方阵营的 45 名角色串在一起。角色不分敌我：墨蚀者和青丘灵族在剧情前半段是对手，打赢、唤醒或结盟后都能招募。角色的数值、技能和羁绊见 [game-design.md](game-design.md) 第 8 节，养成见第 4.8 节，每名角色的个人小故事见 [characters.md](characters.md)。

**最终目的**：一千年前的星线是一道封印，这一次要织的是一张把所有人连起来的网。重织星线需要五根线，五方阵营各出一根，所以收集五方的角色本身就是在推进主线。

## 1. 世界

### 星线是一道封印

一千年前，大地深处醒来一股吞食灵力的饥饿，人们叫它**永夜**。天上的织女带着人间的术士和青丘的灵族，把二十八星宿落下的碎星（**星石**）一颗颗立在九州大地上，照着天上星宿的样子连成**星络**，把永夜压在大地尽头。这群人叫**织网者**，这张网就是**星线**。

这张网只用了两根线：人间术士的知识和青丘灵族的信任。它没有把所有人连起来，只靠一名织网者在初源星石里独自撑着，所以迟早会断。织女回了天上，留在人间的最后一位织网者把自己的魂封进星石，一撑就是一千年。

千年过去，人们忘了星线是封印，只记得它是城池的灯火、结界和田地的来源。青丘灵族记得，但他们不信任再一次贪图灵力的人，退回了山林。

### 断线日

司星监的前任监正**沈寂**观星时发现，封印在衰竭。他不信任任何人，没有告诉学生，也没有去找青丘，而是想独自吞下初源星石的力量，用自己去撑住封印。星历四百一十二年，他打开了初源星石，结果成了第一个被永夜吞掉的人，也就是后来的**永夜之主**。星线从源头开始被永夜吸干，这一天叫**断线日**。

失去灵力的城池结界崩塌，永夜的墨色漫进城里，被墨色沾上的人成了**墨蚀者**。墨蚀者不是天生的妖魔：他们是陷落城池的百姓和守军，记忆被墨色封住，只剩下饥饿。他们吞下的灵力被一路送往初源，喂给永夜。墨蚀者用墨色剪影和发光的眼睛表现，不用骷髅、尸体和血腥。

沈寂的真实动机是第 6 章的反转，在那之前，人们（和玩家）都以为他只是贪图长生。

### 望星城

星线最末端的边城望星城靠一座观星台撑了下来。观星台的星石里住着一缕星魂**阿织**，她能预见战局，却记不起自己是谁。她就是最后一位织网者：断线日那一夜，她从初源退到了星线最末端的这颗星石里，用剩下的光护住望星城。

断线日那一夜，观星台也选中了一个人：只有这个人听得见阿织的声音。这个人就是玩家，望星城新任的**持线人**，要沿着星线一段段打回去，把星石重新点亮。持线人不配语音、不定性别，负责把各方的人连在一起。

### 五根线

| 线 | 阵营 | 什么时候拿到 |
|---|---|---|
| 守护 | 守星军 | 第 1 章，守星军在点亮的第一颗星石前立誓 |
| 自由 | 逐星骑 | 第 2 章，逐星骑答应合作 |
| 救赎 | 墨蚀者 | 第 3 章，被唤醒的灰爪自愿留下 |
| 知识 | 司星监 | 第 6 章，闻道交出沈寂的星图手稿 |
| 信任 | 青丘灵族 | 第 8 章，人与青丘重签织网者之约 |

- 第 1 章阿织就说“要五根线”，但说不清自己怎么知道。主界面的星图上从一开始就有五个空的星宿位，每拿到一根亮一个。
- 最意外的是“救赎”：墨蚀者也能成为一根线。敌人也能收集，在剧情里有了理由。
- 第 4、5、7 章不给线，是有意留的空档：第二幕前半段玩家“还差两根”，阿织又在变暗，压力最大。

### 阿织在变暗

阿织一千年来用自己撑着残存的星线。从第 5 章起，她的光肉眼可见地变弱（观星台和对话立绘都要表现），这是故事里的倒计时。第 8 章她想起了一切，并坦白：重织星线需要有人把五根线打成一个结，她打算成为那个结，永远留在初源。

## 4. 结局与通关总结

通关分五步：前两步收束剧情，后三步回顾玩家自己的这一路，最后给一个继续玩的理由。全部可以跳过，也能在档案馆重看。

1. **决战（第 9 章 Boss 关，两段）**。先打永夜之主沈寂；他倒下后永夜从初源里涌出，第二段打“永夜之心”。第二段里五根线各给一个只能用一次的指挥官技能，剧情和玩法在最后一战合上。
2. **打结**（立绘对话）。阿织要独自留下，岳擎、陆离、朱弦、灰爪、涂山薇各握住一根线，持线人把结打上。重量分给了所有人，阿织不必独自留在初源；但她也不能再住在望星城的一颗星石里，而是散进整张星线，每一颗星石里都有她一点光。她的最后一句是宣传语的变体：“星线不断，我们就不散。”沈寂被洗去墨色，闻道对他说完了当年没说的话。
3. **尾声「后来」**。五方各一张插图和一两句话，讲他们之后的生活。玩家升到 ★5 的角色多一句个人结局（从小传第 5 段延伸），没升满的只出现在阵营那一页，所以每个玩家看到的尾声不一样。招募了雷震英灵的玩家，多一场他和岳擎、凌霄告别的戏。
4. **旅程回顾「星线编年」**。一张星宿图，玩家打过的每一关是图上一颗星，按顺序连成线，旁边弹出几张数据卡：
    - 历时（游戏时长）、战斗场数、点亮的星石数
    - 招募角色数（x / 45）、唤醒的墨蚀者数、最常用的羁绊
    - 「你的老兵」：上阵次数最多的角色，配一句告别语
    - 「最难的一夜」：失败次数最多的一关，和最后打赢它的那一场阵容
    - 战前推演次数（阿织替你看过的战局）
5. **阿织的信和最后一张布阵图**。一封写给持线人的信，模板里嵌 3~4 处玩家数据，例如：“你在墨城前倒下了 7 次，第 8 次是灰爪替你挡住了那一箭。”信后是一张“合影”：玩家最常上阵的角色站在棋盘上，用战斗里的 3D 模型和布阵场景，可以截图分享（分享不换奖励，决策 69）。

**通关之后**

- 解锁两名传说角色、远征的威胁等级、摘星楼更深的区段。
- 档案馆的「星线编年」继续记录；玩家把更多角色升到 ★5，尾声里就多一句他们的结局。
- 片尾彩蛋留一个大悬念：涂山薇望着夜空说，永夜不是这片大地生出来的，它和星石一样，是随那场星雨从天上落下来的。这接上“星线”这个名字，给后续更新留了口子。

**数据记录**：旅程数据（每关胜负和失败次数、上阵阵容、推演次数、首次通关时间）要从第一关起记在存档里，随账号存档保存在服务端。做存档结构时一并考虑。

## 6. 剧情呈现

沿用设计文档第 2.5 节：章节开头和结尾用立绘对话，每章最后一关的结束对话以钩子收尾；战斗中弹出喊话，角色档案在图鉴里随星级解锁。每名角色有一段个人小故事（5 段文本，★1 招募时可看，★2~★5 逐段解锁），全文见 [characters.md](characters.md)。

小游戏玩家多在碎片时间玩：章节对话每段控制在几句，长的剧情放进档案馆，主线关卡里不插长对话。
