# 故事背景与角色关系

主线故事把五个阵营的 45 名角色串在一起。角色不分敌我：亡灵和影歌精灵在剧情前半段是对手，打赢、唤醒或结盟后都能招募。角色的数值、技能和羁绊见 [game-design.md](game-design.md) 第 8 节，养成见第 4.8 节。

## 1. 世界

### 星线是一道封印

一千年前，大陆深处醒来一股吞食法力的饥饿，人们叫它**永夜**。人类法师和影歌精灵联手，把流星雨留下的法力水晶立在大地上，用一根根光带连成**魔网**，把永夜压在大陆尽头。这群人叫**织网者**，这张网就是**星线**。

千年过去，人们忘了星线是封印，只记得它是城邦的灯火、结界和粮田的来源。精灵记得，但他们不信任再一次贪图法力的人类，退回了森林。

### 断线日

王国纪元 412 年，银月法师塔的前任塔主**莫德雷德**想用星线的法力换取永生。他打开了初源水晶，星线从源头开始被永夜吸干，这一天叫**断线日**。莫德雷德成了第一个亡灵，也就是**巫妖王**。

失去法力的城邦结界崩塌，死去的人被永夜的死气唤起，成为亡灵大军。亡灵不是天生的恶魔：它们是陷落城邦的居民和守军，记忆被死气封住，只剩下饥饿。

### 灯塔城

星线最末端的边境城市灯塔城靠一座源晶塔撑了下来。源晶塔的水晶里住着一缕意识**诺娃**，她能预见战局，却记不起自己是谁（她是最后一位织网者）。玩家是灯塔城新任的**指挥官**，要沿着星线一段段打回去，把水晶重新点亮。

## 2. 五个阵营

| 阵营 | 是谁 | 和玩家的关系 | 主题 |
|---|---|---|---|
| **晨星骑士团** | 灯塔城的守军骑士，由老骑士雷恩爵士带领 | 开局就在身边 | 守护：宁可自己倒下，也不让水晶熄灭 |
| **边境游侠会** | 散落在边境行省的猎人、斥候和雇佣兵 | 第一章起陆续加入 | 自由：只为自己认的人拼命 |
| **银月法师塔** | 王国的法师学院，断线日后半数法师失踪 | 第二章起加入，塔里藏着莫德雷德的秘密 | 知识：力量来自理解，也会被它反噬 |
| **亡灵** | 被永夜死气唤起的陷落城邦之民 | 先是敌人；林大师的炼金术和诺娃的星辉能唤醒它们的记忆，唤醒后加入 | 救赎：想起自己是谁，就能选择站在哪一边 |
| **影歌精灵** | 织网者的另一半，守着星线的真相 | 先因误会交战，第三幕结盟 | 信任：一千年前的盟约要不要再签一次 |

## 3. 主线：三幕九章

主线分三幕、九章，每章约 10 个关卡。关卡打通后可以重复挑战（刷经验和角色碎片）。

| 幕 | 章 | 剧情 | 加入的角色（举例） | 章末 Boss |
|---|---|---|---|---|
| 第一幕 边境行省 | 1 灯塔城 | 第一次出城，夺回最近的水晶 | 加文、布兰、罗兰 | 食尸鬼头目 |
| | 2 游侠的森林 | 游侠会在林子里独自抵抗亡灵，答应合作 | 玛塔、托恩、夜莺 | 缝合巨怪莫格 |
| | 3 骸骨要塞 | 攻下亡灵用守军尸骨垒起的要塞；林大师在废墟里唤醒了第一个亡灵灰爪 | 卡西、灰爪 | 骸骨要塞 |
| 第二幕 王国腹地 | 4 银月法师塔 | 法师塔被围；救出赛琳和阿尔德大法师 | 赛琳、泽恩、铁砧 | 女妖赛薇（唤醒后加入） |
| | 5 饥饿的城邦 | 亡灵在吞食水晶，变得越来越强；吸魔者卡斯其实是被困的城邦法师 | 莫娜、欧文、卡斯 | 吸魔者群 |
| | 6 雷恩的最后一夜 | 噬魔巨龙袭击水晶枢纽，雷恩爵士为守住水晶牺牲；阿尔德说出莫德雷德是他的老师 | 奥莉薇亚、哈罗德、维克多 | 噬魔巨龙 |
| 第三幕 永夜之地 | 7 迷雾森林 | 精灵以为人类又来抢水晶，双方交战；维拉出面停战 | 希尔瓦、莉安、塞伦 | 老橡（结盟后加入） |
| | 8 初源之路 | 人类和精灵重签织网者盟约；诺娃想起了自己的身世 | 维拉、埃兰、卡蕾、伊娜 | 血族骑士瓦伦 |
| | 9 初源水晶 | 和巫妖王莫德雷德决战，重新织起星线的源头 | 法埃、瓦伦 | 巫妖王 |

- 雷恩爵士在第 6 章牺牲后，作为“英灵”可以招募（集齐碎片），剧情里由诺娃把他的意识留在水晶中。
- 通关后解锁两名传说角色：被净化的**噬魔巨龙**和放下执念的**莫德雷德**（见 4.8 节的传说角色）。

## 4. 角色关系

故事靠角色之间的关系串起来，战斗喊话和章节对话都从这里取材。

| 关系 | 说明 |
|---|---|
| 雷恩 → 加文、卡西 | 雷恩是两人的老师。雷恩牺牲后加文接任骑士团长，卡西一度离队去找噬魔巨龙报仇 |
| 卡西 ↔ 菲恩 | 菲恩是卡西的狮鹫侍从，崇拜她，总想证明自己 |
| 罗兰 ↔ 夜莺 | 老相识。夜莺曾是游侠会的人，因为一次背叛离开；罗兰一直想知道真相 |
| 玛塔 → 低语 | 低语生前是玛塔的妹妹。玛塔改打怨灵，是想找到她 |
| 赛琳 ↔ 铁砧 | 铁砧是赛琳亲手造的魔像，只听她的话 |
| 阿尔德 → 莫德雷德 | 阿尔德是莫德雷德的学生，觉得自己没能阻止老师，一直在赎罪 |
| 林大师 → 灰爪、维克多 | 林大师用炼金术唤醒亡灵；维克多是叛逃的死灵法师，帮林大师研究唤醒的方法 |
| 胖汤姆 ↔ 小麦 | 憎恶胖汤姆生前是磨坊主，草药师小麦小时候常去他的磨坊 |
| 维拉 ↔ 诺娃 | 维拉认出诺娃是最后一位织网者，也是精灵相信人类的唯一理由 |
| 老橡 ↔ 托恩 | 驯兽师托恩是少数和精灵有来往的人类，老橡认得他 |

## 5. 剧情呈现

沿用设计文档第 2.5 节：章节开头和结尾用立绘对话，战斗中弹出喊话，角色档案在图鉴里随好感和星级解锁。每名角色有一段个人小故事（3~5 段文本），升星时逐段解锁。
