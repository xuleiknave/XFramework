# 故事与章节

> v6.0（决策 77）：题材从“西游后传”改回《西游记》原著原班人马。故事就是原著：序章大闹天宫，正篇按原著重走取经路。星线、永夜、阿织、持线人等后传设定和全部原创角色都去掉了（v5.0 原文见 git 历史）。人物只借原著的名字、身份和经历，造型、台词不参考任何影视、动画和游戏改编。

**一句话**：五行山下压了五百年的猴子出来了。你是土地公请来的引路人，带着唐僧师徒往西走，过九九八十一难。

## 1. 玩家和参谋

- **引路人（玩家）**：土地公请来替师徒排兵布阵的人。不露面、不配语音、不定性别，取名在打完第一关之后。
- **土地公**：取经队随行一座土地庙，庙里住着一位爱唠叨的土地公。原著里悟空每到一处，一跺脚就把当地土地叫出来问话；游戏里由他负责战前推演、关卡开头和结尾的旁白，结局给玩家写一封信。
- **灵石和灵脉**：战场上的灵力节点叫灵石，节点之间连成灵脉。妖怪也有自己的灵脉（妖坛、妖碑）。规则见 game-design.md 第 6 节。

## 2. 四族

阵营按人、仙、魔、兽四族分。完整名单 232 名见 [roster.md](roster.md)，先写进语言表的 47 名见 [characters.md](characters.md)。

| 族 | 是谁 | 一句话 |
|---|---|---|
| **人族** | 取经人唐僧、路上的凡人、门神 | 凡人没有法力，可人心齐了，比什么法宝都硬 |
| **仙族** | 天庭的神将星官、修道的仙人，悟空、八戒、沙僧三位有仙籍的徒弟 | 腾云驾雾，倒下了也能再站起来 |
| **魔族** | 以人形出战的妖王和精怪 | 占山为王，法宝和妖法最多，下手也最狠 |
| **兽族** | 坐骑神兽、四海龙族和水族、现出本相出战的二十八宿 | 现出本相时最凶 |

如来、观音、玉帝、太上老君等尊神只在剧情里出场，不上阵、不进卡池、不当敌人。

## 4. 结局与通关总结

全部可以跳过，也能在档案馆重看。

1. **决战（第 13 章狮驼岭，两段）**：先打青狮白象，再追大鹏。第 14 章灵山没有战斗。
2. **取得真经**（立绘对话）：师徒各说一句，唐僧说“十四年了”。回程路过通天河，老鼋问起那句话，唐僧忘了问，老鼋一沉身把师徒翻进河里，这是最后一难。
3. **尾声「后来」**：四族各一张插图和一两句话。玩家升到 ★5 的角色多一句个人结局（小传第 5 段），所以每个玩家看到的尾声不一样。
4. **旅程回顾「八十一难」**：一张西行路线图，玩家打过的每一关是路上的一难，旁边几张数据卡：历时、战斗场数、夺回的灵石、招募角色数、收服的妖王、最常用的羁绊和八门阵、「你的老兵」（上阵最多的角色）、「最难的一难」（失败次数最多的一关和最后打赢的阵容）、土地公推演的次数。
5. **土地公的信和最后一张布阵图**：信里嵌 3~4 处玩家数据；信后是一张“合影”，玩家最常上阵的角色站在棋盘上，可以截图分享（分享不换奖励，决策 69）。

片尾：经书晒在通天河边的石头上，有几页粘住了，揭下来时破了一角。唐僧说：“天地本不全，经文残缺，也应不全之奥妙。”（原著第九十九回）

**通关之后**：解锁传说角色、远征的难度阶梯、镇妖塔更深的区段；以后的更新补原著里没做的路段。

**数据记录**：旅程数据（每关胜负和失败次数、上阵阵容、八门阵朝向、推演次数、首次通关时间）从第一关起记在存档里，随账号存档保存在服务端。

## 6. 剧情呈现

沿用设计文档第 2.5 节：章节开头和结尾用立绘对话，每章最后一关的结束对话以钩子收尾；战斗中弹出喊话，角色档案在图鉴里随星级解锁。每名角色有一段 5 段的小传（★1 招募时可看，★2~★5 逐段解锁），全文见 [characters.md](characters.md)。

小游戏玩家多在碎片时间玩：章节对话每段控制在几句，长的剧情放进档案馆，主线关卡里不插长对话。
