## 1. 概述

### 1.1 一句话介绍

**指挥人类舰队，从保卫地球开始，一路打进太阳系，最终穿越星门征战宇宙。** 收集和改装兵器，逐级突破“地球级 → 太阳系级 → 宇宙级”，在可暂停的即时战斗中运用补给与威慑取胜。

### 1.2 设计目标

| 目标 | 具体要求 |
|---|---|
| **单机、不打卡** | 没有每日任务、体力、限时活动；哪天不玩也不会落后 |
| **简单易上手** | 每进入一个新层级只新增少量机制，循序渐进 |
| **每天 30 分钟玩遍所有玩法** | 一次远征 15~20 分钟，主线关卡每关 3~5 分钟 |
| **长期吸引** | 随机远征、收集图鉴、羁绊流派、难度阶梯、停级精通 |
| **有故事** | 每个关卡都有剧情推进，三部曲结构 |

### 1.3 参考游戏

| 游戏 | 借鉴点 |
|---|---|
| FTL：超越光速 | 太空远征、补给管理、可暂停的即时战斗 |
| 杀戮尖塔 | 随机路线、难度阶梯（进阶等级） |
| 王国保卫战 | 关卡地图、每关 3 星、剧情插图式叙事 |
| 小丑牌 / 自走棋 | 组合羁绊、流派构筑 |
| 梦幻西游 | 等级突破与停级 |

### 1.4 平台与商业模式

- **平台**：PC（Steam）首发，后续移植手机和主机。
- **商业模式**：买断制（建议定价 30~70 元人民币），后续推出 DLC（新阵营、新篇章）。
- **无内购、无广告**。

## 2. 世界观与剧情

### 2.1 故事背景

2187 年，人类已在近地轨道建立太空电梯和空间站，但从未离开过月球轨道。

一天，月球背面的深空雷达收到一段重复的信号，人们称之为“回声”。三个月后，**蜂群**的先遣部队从天而降，地球各地的防线接连失守。

玩家扮演地球防卫军“晨星部队”的年轻指挥官，在 AI 副官诺娃的协助下，带领残存的部队展开反击。

### 2.2 势力

| 势力 | 身份 | 风格 |
|---|---|---|
| **晨星部队 / 星盟**（玩家） | 人类防卫军，后发展为人类星际联盟 | 均衡，重装甲、强护盾，可学习敌方科技 |
| **蜂群** | 机械智能集群，故事前期的主要敌人 | 数量庞大、廉价、可自我修复 |
| **虚空行者** | 古老的能量文明，宇宙篇登场 | 隐形、跃迁突袭、高爆发 |
| **寂灭** | 隐藏在银河核心的终极威胁，最终敌人 | 吞噬恒星的存在，后期揭晓 |

### 2.3 主要角色

| 角色 | 身份 | 作用 |
|---|---|---|
| 指挥官（玩家） | 晨星部队指挥官 | 主角，可自定义名字和头像 |
| 诺娃 | AI 副官 | 战术提示、教学引导、剧情主线人物（身世之谜） |

### 2.5 剧情的呈现方式

为控制成本，不做过场动画，采用以下方式：

| 方式 | 说明 | 用在哪里 |
|---|---|---|
| **立绘对话** | 角色半身立绘 + 对话框 | 每关开始前、结束后 |
| **战斗通讯** | 战斗中屏幕角落弹出角色头像和短句，不暂停游戏 | 关卡中的关键时刻 |
| **章节插画** | 一张全屏插画加旁白文字 | 每章开头和结尾 |
| **图鉴档案** | 敌人、兵器、地点的背景故事，收集后解锁 | 图鉴系统 |
| **可跳过** | 所有剧情都可以跳过，可在档案中重看 | 全部 |

## 3. 游戏结构

### 3.1 整体循环

```
            ┌──────────────────────────────────┐
            ▼                                  │
     【战役地图】选择关卡                         │
        │                                     │
        ├─▶ 主线关卡 ──▶ 剧情推进、解锁兵器、经验 ──┤
        ├─▶ 支线挑战 ──▶ 星星、图鉴、涂装 ─────────┤
        ├─▶ 远征 ─────▶ 经验、兵器、模块、资源 ────┤
        │                                     │
        ▼                                     │
     【母港】升级、改装、编队、图鉴 ───────────────┘
        │
        ▼
     达到层级等级上限 ──▶ 突破战（或选择停级）
```

### 3.2 每天 30 分钟

| 时间 | 内容 |
|---|---|
| 10 分钟 | 推进 2~3 个主线关卡，看剧情 |
| 15 分钟 | 一次远征 |
| 5 分钟 | 回母港升级、改装、看图鉴 |

### 3.3 等级与层级

| 层级 | 等级范围 | 战场 | 新增机制 |
|---|---|---|---|
| **地球级** | 1~30 | 地表、海洋、大气层、近地轨道 | 基础战斗、克制关系、补给点数 |
| **太阳系级** | 31~60 | 行星表面、卫星轨道、小行星带 | 引力井、短距跃迁、补给线 |
| **宇宙级** | 61~100 | 星系之间、星云、虫洞 | 威慑、阵营羁绊、超大规模舰队战 |

- **经验来源**：主线关卡（多）、远征（中）、支线挑战（少）。
- **节奏目标**：正常推进主线，加上每个区域 1~2 次远征，就能满足后续关卡的等级要求，**不需要专门刷级**。

### 3.4 突破与停级

**突破**

- 达到层级等级上限（30 / 60）后，主动开启“突破战”。
- 击败突破战 Boss 后进入下一层级，解锁新地图、新兵器、新机制。
- 等级到了**不会自动突破**，由玩家决定。

**停级**

停在当前层级，可以获得：

| 内容 | 说明 |
|---|---|
| 层级精通挑战 | 当前层级的“威胁等级 1~10”，每级给敌人加一条增强规则 |
| 极限养成 | 兵器可强化到当前层级的上限 |
| 层级专属奖励 | 精通挑战的称号、涂装、旗舰外观，只能在停级时通过精通挑战获得 |
| 层级图鉴 | 收集当前层级的全部兵器和档案 |

**回访**：突破后可以随时回到之前的层级打主线、支线和远征，补齐图鉴。但**层级精通挑战的专属奖励只能在停级时获得**，保留停级的意义。

## 4. 关卡设计

### 4.1 关卡数量

| 层级 | 章节 | 每章关卡 | 主线关卡 | 突破战 / 最终战 |
|---|---|---|---|---|
| 地球级 | 5 章 | 6 关 | 30 关 | 1 关 |
| 太阳系级 | 5 章 | 6 关 | 30 关 | 1 关 |
| 宇宙级 | 5 章 | 8 关 | 40 关 | 1 关 |
| **合计** | **15 章** | | **100 关** | **3 关** |

在此基础上：

- **困难模式**：通关某一章后解锁该章的困难版本（敌人更强、配置变化、新的支线目标），关卡数量翻倍到 **200 关**。
- **每关 3 颗星**：完成关卡得 1 星，完成两个支线目标各得 1 星，共 **600 颗星**可收集，星星用于解锁图鉴奖励。
- **远征**：随机生成，无限重玩。

每一章的结构：

```
关卡 1~2  ：引入本章新敌人或新机制
关卡 3~4  ：组合运用
关卡 5    ：特殊玩法关（护送、防守、生存等）
关卡 6    ：章节 Boss（宇宙级为关卡 8）
```

### 4.2 关卡类型

一百关不需要一百种全新设计，而是用以下**关卡模板**搭配不同地图、敌人配置和剧情：

| 类型 | 胜利条件 | 特点 |
|---|---|---|
| 歼灭 | 消灭全部敌人 | 最基础的类型 |
| 防守 | 在敌人波次进攻下坚守指定时间 | 布阵为主 |
| 护送 | 保护运输舰到达终点 | 需要分兵保护 |
| 突袭 | 在限定时间内摧毁指定目标 | 节奏快，考验路线选择 |
| 占领 | 占领并守住若干据点 | 补给站争夺 |
| 生存 | 在越来越强的敌人中存活 | 后期关卡 |
| 断补给 | 切断敌方补给线后决战 | 体现补给机制 |
| Boss | 击败巨型敌人 | 每章结尾，有多个阶段 |

### 4.3 支线挑战示例

- 不损失任何单位
- 只使用指定类型的兵器
- 在 X 分钟内获胜
- 不使用跃迁增援
- 至少击毁 X 个敌方补给单位
- 在被威慑状态下获胜

### 4.4 关卡制作方式

- 所有关卡都由**配置数据**驱动：地图、敌人部署、波次、胜利条件、剧情触发点。
- 开发 **Unity 关卡编辑器工具**，可视化摆放敌人和地图元素，导出配置文件。
- 地图素材**按章节复用**：同一章的 6~8 关共用一套场景素材，通过不同的地形布置和视角区分。

## 5. 战斗系统

### 5.1 基本规则

- **即时战斗，可随时暂停**：暂停时可以下达指令，适合策略思考，不拼手速。
- **速度调节**：0.5 倍、1 倍、2 倍。
- **单场战斗时长**：主线关卡 2~4 分钟，远征战斗 1~2 分钟。
- **2.5D 战场**：单位在平面上移动，三维画面加斜俯视镜头。

### 5.2 指令

| 指令 | 操作（PC） | 说明 |
|---|---|---|
| 选中 | 左键点击 / 框选 | Ctrl + 数字编组，数字键快速选组 |
| 移动 | 右键点击空地 | 沿途遇敌自动开火 |
| 集火 | 右键点击敌人 | 优先攻击该目标 |
| 撤退 | R | 退回补给范围，期间受到的伤害降低 |
| 技能 | Q / W / E | 释放所选单位的主动技能 |
| 增援 | 拖动兵器卡到战场 | 消耗补给点数，只能部署到己方控制区 |
| 暂停 | 空格 | 暂停中也可下达所有指令 |

单位都有自动战斗 AI，不操作也能打；操作带来的是战术优势。

### 5.3 补给（地球级起）

**局内补给点数**

- 随时间恢复，用于增援和部分技能。
- 占领补给站可以提高恢复速度。

**补给范围（太阳系级起完整开放）**

- 母港、补给站、支援单位周围有补给范围。
- 单位离开补给范围过久：导弹类弹药逐渐耗尽，护盾停止恢复。
- 击毁敌方支援单位、切断补给线是重要战术。

**远征中的补给**

- 每跳一个星区消耗燃料，战斗消耗弹药，受损单位需要修理。
- 补给不足时需要冒险选择路线，或者放弃受损单位。

### 5.4 威慑（宇宙级完整开放）

**局内威慑**

- 根据双方场上兵力价值对比实时计算。
- 一方兵力价值超过对方 1.5 倍时，对方进入**被威慑状态**：射速下降 10%，占领速度下降。
- 弱势方击毁对方高价值单位时触发“士气爆发”：短时间伤害提升，并解除被威慑状态。

**远征中的威慑**

- 遭遇比自己弱很多的敌人时，可以选择“威慑”：敌人直接投降并交出部分物资，跳过战斗。
- 舰队越强，远征越顺畅，玩家能直接感受到成长。

### 5.5 克制关系

| 兵种 | 克制 | 被克制 |
|---|---|---|
| 战机群 | 大型舰船 | 防空单位 |
| 防空 / 护卫 | 战机群 | 导弹 / 鱼雷单位 |
| 导弹 / 鱼雷 | 护卫、中型单位 | 战机群 |
| 主力（巡洋 / 主战） | 导弹单位 | 重型单位 |
| 重型（战列 / 重型机甲） | 主力、护卫 | 战机群 |
| 支援 | — | 所有攻击单位 |

### 6.1 各层级兵器

| 层级 | 数量 | 兵器示例 |

**跨层级使用**：低层级兵器可以升级为高层级版本（例如“空天战机”升级为“宇宙战机群”），玩家培养的兵器不会作废。

### 6.2 稀有度

普通 → 稀有 → 史诗 → 传说。稀有度越高，**技能越特殊**，但基础数值不碾压低稀有度。

|---|---|---|
| 兵器 | 26 种 | 主线解锁、远征掉落 |

| 改装模块 | 40 个 | 远征、支线挑战 |
| 涂装 | 50 个以上 | 星星奖励、精通挑战、成就 |
| 档案 | 100 条以上 | 关卡、图鉴 |

## 7. 养成系统

### 7.1 母港

母港是玩家的大本营，随剧情推进从地面基地升级为太空要塞。

| 设施 | 作用 |
|---|---|
| 指挥中心 | 选择关卡、查看战役地图 |
| 研发中心 | 用资源升级兵器 |
| 改装车间 | 安装和更换改装模块 |
| 编队室 | 组建和保存编队 |
| 档案馆 | 图鉴、剧情回看、成就 |

母港设施本身也可以升级，解锁更多编队槽位、改装槽位、起始补给。

### 7.2 编队

- 每支编队：**1 个指挥单位 + 最多 8 个兵器**。
- **指挥点上限**：所有兵器的指挥点之和不能超过上限，上限随等级提升。

### 7.3 升级与改装

| 方式 | 效果 |
|---|---|
| 升级 | 提升基础属性，上限受当前层级限制 |
| 改装模块 | 每个兵器 2~3 个插槽，改变玩法风格 |
| 涂装 | 纯外观 |

升级所需的材料全部来自关卡战利品，详细规则见第 8 节。

### 7.4 羁绊

编队中满足条件时激活加成，鼓励尝试不同组合：

| 羁绊示例 | 条件 | 效果 |
|---|---|---|
| 钢铁洪流 | 3 个重型单位 | 全体装甲提升 |
| 制空权 | 3 个战机单位 | 战机出击速度提升 |
| 后勤保障 | 2 个支援单位 | 补给范围扩大 |
| 蜂群同化（宇宙级） | 3 个蜂群单位 | 被击毁的单位有几率重生 |
| 虚空共鸣（宇宙级） | 2 个虚空行者单位 | 跃迁冷却缩短 |

首发计划 **8~10 种羁绊**。

## 8. 战利品与装备强化

核心循环：**打关卡 → 掉落战利品 → 强化兵器 → 战力提升 → 挑战更难的关卡。**

### 8.1 战利品种类

| 类别 | 名称 | 用途 | 主要来源 |
|---|---|---|---|
| 通用货币 | 信用点 | 所有升级的基础费用、远征商店购买 | 所有关卡 |
| 基础材料 | 合金 | 兵器升级 | 所有关卡 |
| 基础材料 | 能源电池 | 技能升级 | 所有关卡 |
| 层级材料 | 稀土合金（地球级）/ 氦-3（太阳系级）/ 虚空晶体（宇宙级） | 兵器进阶、跨层级升级 | 对应层级的关卡 |
| 兵器碎片 | 各兵器专属碎片 | 解锁新兵器、兵器升星 | 指定关卡、Boss、远征精英 |
| 改装模块 | 武器 / 护盾 / 引擎 / 特殊类模块 | 安装到兵器插槽 | 支线 3 星、困难模式、远征 |
| 收集品 | 涂装、档案 | 外观与剧情 | 星星奖励、Boss、隐藏目标 |

### 8.2 掉落规则

| 情况 | 掉落内容 |
|---|---|
| **首次通关** | 固定的大量奖励，通常包含新兵器或兵器碎片 |
| **重复挑战** | 随机掉落，数量较少，但可以无限次挑战（没有体力限制） |
| **星级加成** | 关卡达到 3 星后，重复挑战掉落数量提高 50% |
| **章节 Boss** | 必定掉落稀有以上的兵器碎片或改装模块 |
| **困难模式** | 掉落普通模式没有的稀有模块和兵器变体 |
| **远征** | 掉落数量最多、种类最随机，是刷材料的主要途径 |

**掉落预览**：每个关卡在进入前展示可能掉落的物品，玩家可以针对性地去打某一关，收集自己需要的材料。

**保底机制**：稀有物品连续若干次没有掉落时，下一次必定掉落，避免运气太差。

**设计原则**：正常推进主线就能获得足够的材料跟上关卡难度；刷材料是为了“更强”和“更快”，不是“必须”。

### 8.3 兵器强化方式

| 方式 | 消耗 | 效果 | 上限 |
|---|---|---|---|
| **等级升级** | 信用点 + 合金 | 结构值、护盾、伤害按等级成长 | 不超过指挥官当前等级 |
| **升星**（1~5 星） | 兵器碎片 | 每升一星属性大幅提升；3 星、5 星时技能获得新效果 | 5 星 |
| **技能升级** | 能源电池 | 技能伤害提高、冷却缩短 | 技能 10 级 |
| **进阶** | 层级材料 | 低层级兵器升级为高层级版本（如“空天战机”进阶为“宇宙战机群”），解锁新外观和新技能 | 每个层级一次 |
| **模块强化** | 信用点 + 同类模块 | 模块效果从 +0 强化到 +10 | +10 |

**停级的联系**：等级升级上限受指挥官等级限制，停级的玩家可以把升星、技能、模块强化做到满，打造“同等级最强”的编队，挑战层级精通。

### 8.4 战力

**单个兵器战力**由等级、星级、技能等级、模块综合计算，在界面上用一个数字表示。

**编队战力** = 所有兵器战力之和 + 羁绊加成。

战力在游戏中的作用：

| 用途 | 说明 |
|---|---|
| 推荐战力 | 每个关卡显示推荐战力，编队战力低于推荐值时提示风险 |
| 远征威慑 | 编队战力远高于敌人时，可以直接威慑敌人投降（见 5.4） |
| 成长反馈 | 每次强化后显示战力提升数字和动画，让玩家直接感受到变强 |
| 图鉴成就 | 编队战力达到一定数值解锁称号和涂装 |

**策略仍然重要**：
- 战力只是参考，**合理的布阵和克制可以战胜高出 20% 左右战力的敌人**。
- 很多支线挑战星（例如“不损失单位”）需要靠战术完成，单纯堆战力拿不到。
- 敌人强度按关卡固定，不会随玩家战力变强，所以强化的效果能真实地体现出来。

### 8.5 数值平衡方向

- 每个层级内，满级满星编队的战力大约是刚进入该层级时的 **3 倍**，让成长感明显。
- 新层级的第一关敌人强度高于上一层级满强化的编队，但突破后获得的新兵器和进阶能快速追上，避免“突破后反而打不过”的挫败感。
- 具体数值在 P1 原型阶段，通过战斗内核的批量模拟测试来调整（见 10.2）。

## 9. 远征模式（Roguelite）

### 9.1 流程

```
选择编队出发
   ↓
随机星图（6~8 个节点，多条路线）
   ├─ 战斗：普通敌人
   ├─ 精英：更强敌人，掉落稀有兵器
   ├─ 事件：剧情选择题（救援、遗迹、谈判、交易）
   ├─ 商店 / 船坞：购买、修理、改装
   └─ 终点 Boss
   ↓
结算：带回经验、兵器、模块、资源
```

- 一次远征 15~20 分钟，中途可以存档退出。
- 远征失败也能带回部分资源，不会白打。
- 每个层级有自己的远征地图和敌人池。

### 9.2 远征内的成长

- 远征中获得的临时强化（例如“本次远征所有战机射速 +20%”）只在本次远征有效。
- 鼓励每次尝试不同的流派。

### 9.3 难度阶梯

- 每个层级的远征都有“威胁等级 1~10”（即停级精通挑战，见 3.4）。
- 通关后解锁“无尽星海”：不断深入的无限远征，记录最远距离。

### 9.4 每日星域（可选）

- 每天一张固定种子的星图，全球玩家相同，可上传分数参加排行榜。
- **完全可选，不玩没有任何损失**，没有登录奖励。需要联网，但不影响单机游玩。

## 10. 技术架构

### 10.1 总体结构

单机游戏不需要服务器（每日星域的排行榜可以使用 Steam 自带的排行榜功能）。

```
Unity 客户端
├── 表现层：场景、单位、特效、UI、剧情对话
├── 游戏流程层：战役地图、母港、远征、存档
└── 战斗内核（纯 C# 类库，不依赖 Unity）
    ├── 单位、武器、技能
    ├── 补给、威慑
    ├── AI（行为树）
    └── 确定性随机数
```

### 10.2 关键技术决策

| 决策 | 理由 |
|---|---|
| 战斗内核与 Unity 分离 | 便于写自动化测试和平衡性测试（无界面批量模拟战斗） |
| 确定性随机数 + 固定种子 | 远征可复现，便于调试；每日星域需要所有玩家结果一致 |
| 数据驱动 | 兵器、关卡、剧情、远征事件全部用配置文件描述，方便调整和扩充内容 |
| 本地存档 + Steam 云存档 | 换电脑可以继续游戏 |
| 自研关卡编辑器 | 100 关以上的关卡制作需要高效工具 |

### 10.3 数据文件

```
data/
├── units/          兵器属性、技能
├── modules/        改装模块
├── loot/           掉落表、材料、强化消耗与成长曲线
├── synergies/      羁绊
├── levels/         关卡配置（按章节）
├── story/          剧情对话脚本
├── expedition/     远征节点、事件、敌人池
└── localization/   多语言文本（中文、英文起步）
```

### 10.4 代码仓库结构

```
XFramework/
├── docs/                         设计文档
├── src/
│   ├── XFramework.Battle/        战斗内核
│   └── XFramework.Battle.Tests/  内核测试、平衡性模拟
├── data/                         游戏数据配置
└── UnityClient/                  Unity 工程（含关卡编辑器）
```

## 11. 美术与音效

- 音效与音乐前期使用商用素材库，后期定制主题曲。

## 13. 开发路线图

| 阶段 | 目标 | 主要内容 | 验收标准 |
|---|---|---|---|
| **P0 战斗原型** | 验证战斗好玩 | 3 种兵器、1 张地图、框选 / 移动 / 集火 / 暂停、简单敌人 AI；使用方块等占位模型 | 找人试玩，觉得“想再打一局” |
| **P1 核心机制** | 补给与克制 | 补给点数、补给站、增援、技能、克制关系 | 出现“靠补给或克制翻盘”的对局 |
| **P2 关卡框架** | 能做关卡 | 关卡配置格式、关卡编辑器、6 种关卡模板、剧情对话系统 | 用编辑器在 1 天内做出 3 个可玩关卡 |
| **P3 垂直切片** | 完整体验第一章 | 第 1 章 6 关、剧情、母港、战利品掉落与兵器强化、战力显示、存档 | 新玩家从开头玩到第 1 章 Boss，体验完整 |
| **P4 远征** | 可重玩内容 | 随机星图、事件、商店、远征结算 | 连续打 5 次远征，每次体验都不同 |
| **P5 地球篇完成** | 第一部完成 | 地球篇 30 关、8 种兵器、突破战、停级与精通挑战 | 地球篇完整可玩，可作为 Steam 试玩版 |
| **P6 抢先体验** | Steam 抢先体验 | 美术替换、音效、Steam 页面、成就、云存档 | 上线抢先体验，收集玩家反馈 |
| **P7 太阳系篇** | 第二部 | 太阳系篇 30 关、新机制、新兵器 | 抢先体验更新 |
| **P8 宇宙篇与正式版** | 第三部 | 宇宙篇 40 关、威慑、羁绊、结局、困难模式 | 正式版发布 |

**发行策略**：地球篇完成后先上 **Steam 抢先体验（Early Access）**，边卖边开发后两部。这样能尽早获得收入和反馈，降低个人开发的风险。
