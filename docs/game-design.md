# Starline（星线）游戏设计文档（GDD）

> 版本：v3.0
> 日期：2026-10-20
> 类型：单机奇幻战略 / 布阵自动战斗 / Roguelite 远征 / 收集解锁
> 平台：PC（Steam）首发
> 代码仓库代号：XFramework
>
> v3.0 把背景从太空科幻换成奇幻“魔网”：舰船改为部队，补给网络改为由法力水晶组成的魔网，蜂群改为亡灵。玩法、数值和代码里的单位 id 都没有变。v2.0（太空舰队“重建星线”）和更早的版本见 git 历史。

## 1. 概述

### 1.1 一句话介绍

**亡灵吸干了连接人类城邦的法力水晶网络“星线”。你率领晨星远征军，一段一段重新点亮星线：战前排兵布阵、铺设魔网，开战前先推演一百场战争，然后看部队自动交战。**

### 1.2 设计目标

| 目标 | 具体要求 |
|---|---|
| 单机为主、不打卡 | 没有每日任务和体力；在线功能都是可选的 |
| 每天 30 分钟玩得完整 | 一局远征 25~30 分钟；常驻玩法一层 1~2 分钟 |
| 策略在布阵 | 选兵、站位、魔网、克制；战斗自动进行，只保留少量指挥官技能 |
| 有辨识度 | 魔网和战前推演是同类游戏没有的核心机制 |
| 长期吸引 | 每局不同的远征、难度阶梯、解锁与图鉴、炼金工坊研究、无尽的星辉高塔 |

### 1.3 参考游戏

| 游戏 | 借鉴点 |
|---|---|
| 背包乱斗 / Mechabellum | 布阵自动战斗、异步对战其他玩家的阵容 |
| 杀戮尖塔 | 随机路线、难度阶梯 |
| FTL：超越光速 | 远征、资源和补给管理 |
| 云顶之弈 / 自走棋 | 合成升星、阵容搭配 |

### 1.4 平台与商业模式

- **平台**：PC（Steam）首发；以后可考虑移植手机或微信小游戏。
- **引擎**：Unity 6（开发使用 6000.6.6），URP 渲染管线，HDR 与后处理。
- **商业模式**：Steam 买断制（建议 30~70 元人民币），后续 DLC（新阵营、新行省）。无内购、无广告。
- **发行策略**：第一幕完成后上 Steam 抢先体验，边卖边做后两幕。

## 2. 世界观与剧情

### 2.1 背景

很久以前，一场流星雨落在大陆上，碎片化成了蕴含法力的水晶。人们把水晶一颗颗立在城邦之间，让法力沿着水晶传递，织成一张覆盖王国的**魔网**。夜里水晶连成的光带像落在地上的星河，所以人们叫它**“星线”**。城邦的结界、灯火、粮田和通信，全靠星线供给法力。

王国纪元 412 年，大陆尽头的永夜之地涌出了**亡灵**。它们以法力为食，一夜之间吸干了成千上万颗水晶，星线断成了碎片。这一天后来被称为“断线日”。失去法力的城邦结界崩塌，一个接一个陷落。

星线最末端的边境城市“灯塔城”靠着一座源晶塔幸存了下来。玩家是驻守在这里的**晨星远征军**指挥官，任务是：**沿着星线一段段打回去，重新点亮水晶，把孤立的城邦重新连起来。**

**核心主题**：魔网就是生命线。战斗里你在布置魔网，剧情里你在重建整个王国的魔网。宣传语：“星线不断，人类不灭。”

### 2.2 势力

| 势力 | 身份 | 风格 |
|---|---|---|
| **晨星远征军**（玩家） | 灯塔城的人类远征军：骑士、游侠、法师和狮鹫骑手 | 均衡，依赖魔网；炼金工坊能解析敌方的力量 |
| **亡灵** | 以法力为食的不死大军 | 数量多、骸骨与腐肉外形；也有自己的“骨碑”魔网，从亡灵祭坛汲取死气 |
| **影歌精灵** | 隐居森林的古老种族，第三幕登场 | 隐身、闪现突袭；从敌人变为盟友 |

### 2.3 主要角色

| 角色 | 身份 | 作用 |
|---|---|---|
| 指挥官（玩家） | 晨星远征军指挥官 | 主角 |
| 诺娃 | 栖身在源晶塔水晶里的星灵，远征军的参谋 | 战前推演的“参谋”（用水晶预见战局）；身世是剧情主线之谜 |
| 雷恩爵士 | 老骑士，灯塔城守备司令 | 第一、二幕的导师，第二幕为守住水晶牺牲 |
| 林大师 | 首席炼金师 | 负责炼金工坊和解析研究 |
| 卡西 | 王牌狮鹫骑士 | 擅长切断敌方魔网，战斗中常有喊话 |
| 维拉 | 影歌精灵使者 | 第三幕登场，揭示星线的真相 |

### 2.4 三幕剧情（一局远征的三幕）

| 幕 | 区域 | 剧情 | 幕末 Boss |
|---|---|---|---|
| 第一幕 | **边境行省** | 从灯塔城出发，夺回第一批水晶，连通三座边境城邦 | **骸骨要塞**：亡灵用断线日倒下的守军尸骨和碎水晶垒成的要塞 |
| 第二幕 | **王国腹地** | 连通被围困的城邦；发现亡灵在吞食水晶里的法力并不断变强；雷恩爵士为守住水晶牺牲 | **噬魔巨龙**：吞下了一整座水晶枢纽的骨龙 |
| 第三幕 | **永夜之地** | 与影歌精灵从交战到结盟，得知星线最初是为了封印亡灵而织成的；诺娃是织网者留在水晶里的一缕意识 | **巫妖王**：盘踞在星线起点“初源水晶” |

- 每次远征都完整打一遍三幕。
- **剧情按进度解锁**：首次到达某一幕、首次击败某个 Boss、累计完成远征次数，都会解锁新的剧情片段。通关后解锁“难度阶梯”和后续剧情。

### 2.5 剧情呈现

| 方式 | 用在哪里 |
|---|---|
| 立绘对话 | 每幕开始、Boss 战前后、远征结算 |
| 战斗喊话 | 战斗中屏幕角落弹出角色头像和短句，不暂停 |
| 事件节点 | 远征中的剧情选择题 |
| 档案 | 敌人、部队、水晶、城邦的背景故事，在图鉴中解锁 |

所有剧情都可以跳过，并能在档案馆重看。

## 3. 游戏结构

| 模式 | 节奏 | 作用 |
|---|---|---|
| **主线远征**（第 4 节） | 一局 25~30 分钟 | 主体验：剧情、解锁新部队和符文 |
| **星辉高塔**（第 11 节） | 一层 1~2 分钟 | 常驻休闲：碎片时间玩几层，长期目标是走得更远 |
| **炼金工坊**（第 10 节） | 局外 | 用缴获的遗骸解析敌方的力量 |
| 在线玩法（第 12 节，可选） | — | 异步挑战其他玩家阵容、排行榜 |

**每天 30 分钟**：一局远征；或者打几层星辉高塔，再去炼金工坊领研究成果。

## 4. 主线远征（Roguelite）

流程图见 [prototype/RunFlow.png](prototype/RunFlow.png)。

### 4.1 一局的流程

```
开局：选指挥官，带 3 支初始部队和 1 个指挥官技能
  → 第一幕 边境行省（5~6 个节点）→ Boss：骸骨要塞
  → 第二幕 王国腹地（5~6 个节点）→ Boss：噬魔巨龙
  → 第三幕 永夜之地（5~6 个节点）→ Boss：巫妖王
  → 结算
```

### 4.2 地图节点

| 节点 | 内容 |
|---|---|
| 普通战斗 | 常规敌人，胜利后战利品三选一 |
| 精英战 | 更强的敌人，掉落稀有部队或符文，遗骸掉率更高 |
| 玩家阵容 | 其他玩家在同一幕的真实阵容（异步对战，离线时换成 AI 阵容） |
| 事件 | 剧情选择题：救援难民车队、调查水晶遗迹、和流浪商人交易等 |
| 商店 | 用金币购买部队、符文、指挥官技能 |
| 补给站 | 二选一：恢复 1 点远征军耐久，或领取 1 个法力水晶（P3 加入口粮） |

每次在地图上有 2~3 条路线可选。

### 4.3 战斗循环

```
选节点 → 布阵（可看到敌方阵容）→ 战前推演（可选）→ 自动战斗 20~40 秒
  → 胜利：战利品三选一（部队 / 符文 / 指挥官技能）→ 整备 → 下一个节点
  → 失败：远征军耐久 −1，没有奖励，跳过这个节点回到地图（Boss 战失败 −2，可以重打）
```

### 4.4 局内资源

| 资源 | 规则 |
|---|---|
| 远征军耐久 | 共 5 点；战斗失败 −1，Boss 战失败 −2；归零则本局结束 |
| 金币 | 战斗获得，商店消费（P3） |
| 口粮 | 每跳一个节点消耗；不足时部队法力上限降低，需要去补给站（P3） |
| 指挥点上限 | 第一幕从 12 开始，每过一个战斗节点 +2（输赢都算，避免一场失败滚雪球），最高 24；之后每幕提高起点 |
| 情报点 | 每场战斗 3 点，用于战前推演 |

### 4.5 局内成长

- **合成升星**：3 支同名同星部队自动合成 1 支高一星的（最高 3 星）。★2 耐久（生命、护盾、护盾恢复）×1.6、伤害 ×1.5；★3 耐久 ×2.5、伤害 ×2.2。合成后的部队接替原来的上阵位置。
- **部队不会永久损失**：战斗中倒下的部队战后全部恢复，失败的代价是远征军耐久。
- **符文**：装到部队的符文槽上（见 8.3）。
- **指挥官技能**：最多带 3 个。

### 4.6 局外成长（轻量）

- 新部队、新符文、新指挥官、新指挥官技能**加入奖池**（不是直接变强）。
- 图鉴、成就、外观。
- **难度阶梯**：通关后解锁“威胁等级 1~20”，每级给敌人加一条规则。
- 炼金工坊研究成果（第 10 节）。

### 4.7 第一幕的实现（P2）

已在代码中实现，数值由自动玩家批量模拟校准（`tests/Starline.Battle.Tests`）。

| 项目 | 内容 |
|---|---|
| 开局远征军 | 源晶塔、2 个法力水晶、重甲骑士 / 游侠 / 奥术法师各 1 支（共 10 指挥点） |
| 地图 | 6 层：战斗 ×2 → 战斗、战斗、补给 → 战斗、精英、补给 → 战斗 ×2、精英 → 补给、战斗 → Boss；每层顺序随机，节点连向下一层相邻的 1~2 个节点 |
| 敌方阵容 | 按层分三档：食尸鬼巡逻队、怨灵袭扰 → 骨塔阵地、憎恶之墙 → 墓园前哨、饱食尸群（★2）；精英：缝合巨怪巡游、古战场伏击 |
| Boss | 骸骨要塞：不移动，射程覆盖我方前两排，每第 3 次攻击重炮齐射，带护卫和骨塔 |
| 战利品 | 三选一；一半选项是已拥有的部队（方便合成）；第三个选项有 1/4 概率换成法力水晶（最多 6 个）；精英战第一个选项是 ★2 |
| 奖池权重 | 游侠、弩手、奥术法师、狮鹫骑队各 3，重甲骑士 1（精英战 3） |
| 剧情 | 出发前雷恩爵士的简报、每个节点的情报简报、通关和失败的结尾对话 |

自动玩家（随机选路线、总选第一个奖励、自动布阵、不用指挥官技能）的通关率约 40%，真实玩家调整布阵并使用技能后应明显更高。

## 5. 布阵与战斗

原型图见 [prototype/Formation2.png](prototype/Formation2.png) 和 [prototype/Battle2.png](prototype/Battle2.png)。

### 5.1 布阵棋盘

- **横向战场**：我方在左、敌方在右，双方前排隔着中间的接触线相对。
- 每一方**前排宽 8 格、纵深 6 格**。小型和中型部队占 1 格，**大型单位占 2 × 2 格**。
- 魔网节点放在**格子的交叉点**上，不占格子（见第 6 节）。
- 上阵数量受**指挥点上限**限制。
- 布阵可以保存为方案。

| 位置 | 适合 | 原因 |
|---|---|---|
| 前排 | 重甲骑士、游侠 | 先接敌，承受伤害 |
| 后排 | 奥术法师、源晶塔 | 射程远，需要保护 |
| 两翼（前排的上下两端） | 狮鹫骑队、游侠 | 速度快，绕后攻击 |

**能否看到敌方阵容**：远征的普通节点和星辉高塔可以看到；少数“迷雾”节点看不到；实时对战看不到（见第 12 节）。

### 5.2 自动战斗

- 部队按固有的**索敌偏好**自动选目标：狮鹫骑队优先攻击魔网节点和远程单位，弩手优先攻击狮鹫，奥术法师优先攻击重装单位，其余攻击最近的目标。
- 移动到射程内后攻击；狮鹫在大型单位之间穿梭，不和它们碰撞。
- 可以 1x / 2x / 4x 观看，或者跳过。
- 时间上限 90 秒，到时比较双方剩余作战单位的耐久。

### 5.3 指挥官技能

每场战斗最多带 3 个，消耗**法术点数**（开局 2 点，每秒 +1，上限 10）：

| 技能 | 消耗 | 冷却 | 效果 |
|---|---|---|---|
| 陨星术 | 4 | 10 秒 | 选择落点，1 秒后对范围内敌人造成大量伤害 |
| 守护结界 | 3 | 15 秒 | 全体恢复一半护盾 |
| （更多技能在远征中获得） | | | 传送增援、驱散波、水晶过载等 |

### 5.4 威慑

- 开战时比较双方上阵战力；一方超过对方 1.5 倍时，对方进入“被威慑”：射速 −10%。
- 弱势方击败对方大型单位时触发“士气爆发”，解除被威慑并短时提高伤害。
- 远征中遇到明显弱于自己的敌人时，可以直接威慑对方投降，跳过战斗并拿到一半奖励。

## 6. 魔网（核心玩法）

### 6.1 规则

- 部队占格子；**魔网在另一层：节点放在格子交叉点上，魔网连线沿格线走。**
- 每场战斗己方后方有一座固定的**源晶塔**（大型，占 2 × 2），它前沿中点的交叉点是**源口**。
- 布阵时可以在交叉点上放**法力水晶**，每个消耗 1 指挥点。
- 两个节点在同一条格线上、相距不超过 **3 格**时自动连成魔网连线。
- 每个节点**覆盖周围 2 格**（以交叉点为中心的 4 × 4 区域）。
- 部队只要有一格在覆盖范围内，并且这个范围的节点能沿魔网连线连回源口，就算**接入魔网**。

### 6.2 接入和未接入

| 状态 | 法力 | 护盾恢复 |
|---|---|---|
| 接入魔网 | 持续补充 | 正常 |
| 未接入 | 只有自身的法力，用完就停手 | 停止 |

- 狮鹫骑队有“短时离网”特性：离开覆盖范围后 10 秒内仍算有魔网，适合执行切断任务。

### 6.3 切断

- 战斗中**法力水晶可以被摧毁**；被毁后网络重新计算，下游的节点和部队全部断魔网。
- 亡灵也有自己的魔网（亡灵祭坛 + 骨碑），布阵时可以看到，并规划切断路线。

### 6.4 带来的策略

- 阵型紧凑容易覆盖，但怕范围攻击；阵型分散需要更多水晶。
- 派狮鹫骑队绕后切断敌方魔网，敌方远程单位用光法力就失去威胁。
- 在关键水晶附近放弩手，挡住来切线的怨灵群。

已在战斗内核中实现并测试：默认阵型胜率约 27%；把未接入魔网的奥术法师挪进覆盖区约 77%；去掉全部法力水晶为 0%。

## 7. 战前推演（招牌功能）

- 布阵后点“战前推演”，消耗 1 点情报点，内核在后台用不同随机种子**模拟 100 场**，约 1 秒出结果。
- 结果：**胜率与误差范围、平均用时、平均损失、常见败因、参谋（诺娃）建议、本场推演记录**。
- 限制：
  - 情报点有限（每场 3 点）。
  - 推演不使用指挥官技能。
  - 敌方部分单位有**隐藏特性**，推演按默认值计算，因此有误差；炼金工坊研究可以消除（见第 10 节），商店可以买“侦察”。
  - 真实战斗使用推演中没用过的随机种子。
- 宣传语：“开战之前，你已推演了一百场战争。”

## 8. 部队体系

### 8.1 晨星远征军兵种

| 部队 | 定位 | 尺寸 | 克制 | 被克制 |
|---|---|---|---|---|
| 游侠 | 轻型，快速 | 1 格 | 远程单位 | 重装单位 |
| 重甲骑士 | 重型，耐打 | 2 × 2 | 轻装单位、弩手 | 狮鹫、远程单位 |
| 狮鹫骑队 | 空中骑队，机动，可短时离网 | 1 格 | 重装单位、远程单位、魔网节点 | 弩手 |
| 弩手 | 防御狮鹫 | 1 格 | 狮鹫 | 重装单位 |
| 奥术法师 | 远程火力，法力有限 | 1 格 | 重装单位 | 轻装单位、狮鹫 |
| 源晶塔 | 魔网源头，无武器 | 2 × 2 | — | — |
| 法力水晶 | 魔网节点，无武器 | 交叉点 | — | — |

后续扩充：驯兽师（持续召唤飞兽）、咒术师（干扰魔网连线）、攻城魔像、传送突袭队，以及解析得到的亡灵和影歌精灵部队。首发目标：我方约 20 种部队。

### 8.2 亡灵单位（第一幕）

| 单位 | 定位 |
|---|---|
| 食尸鬼 | 轻型，快速近战 |
| 憎恶 | 重型，耐打 |

### 8.3 固有属性与符文

- 每支部队有**固有属性**（定位、尺寸、生命值、护盾、伤害、射程、速度、法力、固有技能、固有特性），决定它的玩法，任何符文都不能改变定位、射程档位和攻击方式。
- 每支部队有 **3 个符文槽**（槽 1 主动、槽 2 和槽 3 被动；槽 2、槽 3 分别在 2 星、3 星解锁），安装远征中获得的符文。
- **双向装配限制**：部队的槽位规定接受哪些符文类别（攻击 / 防御 / 机动 / 支援 / 咒术 / 特殊）；符文规定适用哪些部队（按定位、尺寸、攻击方式）。两边都满足才能装。
- 符文只做补充：一支部队的战力中，固有属性占 75% 以上，符文不超过 25%。

## 10. 炼金工坊：缴获与解析

原型图见 [prototype/Lab.png](prototype/Lab.png)。

- 远征中缴获的遗骸全部带回灯塔城（失败带回一半）。
- 用遗骸在炼金工坊发起**解析研究**。

**研究时间：现实时间为主，实战缩短为辅**

| 研究对象 | 基础时间 |
|---|---|
| 普通敌人 | 12 小时 |
| 精英敌人 | 18 小时 |
| Boss 武器 | 48 小时 |

- 关闭游戏也会计时；完成后成果一直保留，不会过期。
- **实战缩短随剧情解锁**：

| 阶段 | 解锁时机 | 效果 |
|---|---|---|
| ① | 首次击败骸骨要塞：林大师带回第一批亡灵样本，炼金工坊开放 | 只有现实时间倒计时 |
| ② | 首次击败噬魔巨龙：炼金工坊接入远征军的战报 | 赢一场战斗 −1 小时，击败 Boss −3 小时，完成一局远征 −2 小时 |
| ③ | 首次击败巫妖王：诺娃协助解析，升级为“星辉秘仪室” | 缩短效果翻倍，研究槽 +1 |

- 额外消耗同类遗骸可以加速（每个 −2 小时）。

**研究成果分阶段发放**

| 进度 | 成果 |
|---|---|
| 25% | 揭示该敌人的隐藏特性，以后战前推演对它不再有误差 |
| 60% | 获得它的武器符文图纸，符文加入奖池 |
| 100% | 解析成功，该敌方部队加入奖池和图鉴 |

- 研究不会失败。初始 2 个研究槽，最多 4 个。研究树按阵营分支（亡灵秘术、精灵秘术）。

## 11. 常驻休闲玩法：星辉高塔

原型图见 [prototype/Tower.png](prototype/Tower.png)。

### 11.1 设定

灯塔城外有一座通往云端的远古高塔，每一层都嵌着一颗熄灭的星辉水晶，塔里盘踞着亡灵，没人知道塔顶有什么。远征军沿着这座**星辉高塔**一层层往上打，每打赢一层就点亮一颗水晶。

- 一层一场战斗，1~2 分钟。**没有体力、没有每日次数、进度永久保留。**

### 11.2 深度区段

| 层 | 区段 | 特点 |
|---|---|---|
| 1~20 | 塔基 | 教学性质，敌人以轻装、重装为主 |
| 21~40 | 古战场 | 怨灵群增多，考验弩手布置 |
| 41~60 | 迷雾回廊 | 法力紊乱规则（魔网连线距离缩短等） |
| 61~80 | 虚空裂隙 | 漩涡、传送单位 |
| 81~100 | 亡灵王座 | 高难度规则层和 Boss 集中 |
| 101 层以上 | 无尽星穹（无尽） | 固定种子程序生成，可上排行榜 |

每 10 层：1~8 层普通层（其中 2~3 层带规则），第 9 层精英层，第 10 层 Boss 层兼存档点。

### 11.3 每层的玩法

- **敌方阵容完全公开**，像一道布阵谜题；**失败可无限重试**。
- 每层 2 点情报点，进入新的一层时补满。
- **规则层**（重点考验魔网）：只能放 1 个法力水晶；魔网连线连接距离降为 2 格；看不到敌方后两排；本层没有源晶塔；中央有法力漩涡；敌方怨灵群翻倍。

### 11.4 塔内编队与塔层祝福

- 使用主线和炼金工坊**已解锁**的部队、符文、指挥官技能，**强度统一**，不受养成数值影响。
- 指挥点上限随深度提升（塔基 14 点，每个区段 +4）。
- 每过一个 Boss 层，从 3 个**塔层祝福**中选 1 个长期装上，例如：魔网连线连接距离 +1、法力水晶耐久 +50%、陨星术冷却 −30%、开局法术点数 +2、狮鹫离网时间 +5 秒。最多 6 个，存档点可重新调整。

### 11.5 星级与奖励

- 每层 3 颗星：通关；损失不超过 2 支；本层特殊条件。
- 首通奖励：金币、遗骸、少量局外货币；每 10 层里程碑奖励称号、外观、灯塔城装饰。
- **不发放直接提升战力的物品**。
- 可选排行榜：最高层数、总星数，可只看好友。

## 12. 在线玩法（可选）

不联网也能完整游玩全部内容。

| 玩法 | 规则 |
|---|---|
| 玩家阵容节点 | 远征中遇到其他玩家同一幕的真实阵容（异步，主要的在线内容） |

## 13. 展现方式与美术

- **2D 界面 + 3D 战斗**：灯塔城、地图、商店、炼金工坊、星辉高塔用 2D 界面；布阵和战斗在 3D 场景中。
- **固定镜头**：布阵时接近正俯视；点“开战”后镜头压低，转为从侧前方斜看，远征军从左向右推进。关键时刻自动特写（可关闭）。
- **风格**：低多边形奇幻风格，部队像桌面战棋的棋子小队。晨星远征军是蓝白配色的骑士、游侠和法师；亡灵是灰绿色的骸骨与腐肉，带幽绿光；影歌精灵紫色。
- **渲染**：URP，HDR 泛光让法术、魔网连线、水晶、爆炸发光；ACES 色调映射、暗角。
- **重点投入**：施法和射击、护盾受击、魔网连线断开、水晶点亮、传送、爆炸。
- 部队只需要移动、转向、攻击；尽量用简单的程序动画（弹跳前进、挥砍和施法的光效）代替骨骼动画，控制美术成本。人形单位比舰船更容易让人期待动作，这是换背景后美术上最大的新增成本。

## 14. 技术架构

### 14.1 结构

```
Unity 客户端（Starline/Packages/com.starline.game）
├── Runtime/Client     表现层：GameApp 入口、各界面（UI Toolkit）、布阵与战斗控制、3D 舞台
├── Runtime/Resources  配置表（JSON）、界面布局（UXML）与主题（USS）
└── Runtime/Battle     战斗内核（纯 C#，不依赖 Unity）
    ├── Data           配置读取、部队数据、克制表
    ├── Board          棋盘坐标、布阵规则、魔网
    ├── Sim            战斗模拟、指挥官技能
    ├── Analysis       战前推演
    ├── Expedition     远征：地图、远征军与合成、奖励、自动布阵
    └── Math           定点数、确定性随机数
```

详细说明见 [client-architecture.md](client-architecture.md)。

### 14.2 关键决策

| 决策 | 理由 |
|---|---|
| 内核与 Unity 分离 | 可以写自动化测试；推演能在后台批量模拟 |
| 定点数 + 固定种子 | 结果在任何电脑上一致：推演、回放、在线对战都依赖它 |
| 数据驱动 | 部队、敌人、技能、地图、奖池、剧情文本都在 JSON 配置表里，内核和测试读同一份 |
| 本地存档 + Steam 云存档 | 换电脑可继续 |

### 14.3 仓库结构

```
XFramework/（仓库）
├── Starline/                         Unity 工程
│   └── Packages/com.starline.game/   游戏代码
├── src/Starline.Battle/              用 .NET 编译战斗内核
├── tests/Starline.Battle.Tests/      内核测试与平衡性模拟
└── docs/                             设计文档与原型图
```
