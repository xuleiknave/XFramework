## 1. 概述

### 1.1 一句话介绍

**指挥人类舰队，从保卫地球开始，一路打进太阳系，最终穿越星门征战宇宙。** 收集和改装兵器，逐级突破“地球级 → 太阳系级 → 宇宙级”，战前排兵布阵，战斗自动进行，运用克制、站位、补给与威慑取胜。

### 1.2 设计目标

| 目标 | 具体要求 |
|---|---|
| **单机为主、不打卡** | 没有每日任务、体力、限时活动；哪天不玩也不会落后。在线天梯为可选玩法 |
| **简单易上手** | 每进入一个新层级只新增少量机制，循序渐进 |
| **每天 30 分钟玩遍所有玩法** | 一次远征 15~20 分钟，主线关卡每关 3~5 分钟 |
| **长期吸引** | 随机远征、收集图鉴、羁绊流派、难度阶梯、停级精通 |
| **有故事** | 每个关卡都有剧情推进，三部曲结构 |

### 1.3 参考游戏

| 游戏 | 借鉴点 |
|---|---|
| FTL：超越光速 | 太空远征、补给管理 |
| 自走棋 / Mechabellum | 战前布阵、自动战斗、看阵容找克制 |
| 杀戮尖塔 | 随机路线、难度阶梯（进阶等级） |
| 王国保卫战 | 关卡地图、每关 3 星、剧情插图式叙事 |
| 小丑牌 / 自走棋 | 组合羁绊、流派构筑 |
| 梦幻西游 | 等级突破与停级 |

### 1.4 平台与商业模式

- **平台**：PC（Steam）首发。后续可考虑移植微信小游戏（需改用团结引擎导出、首包小于 4MB、触屏操作、激励视频广告变现）和手机 App。
- **引擎**：Unity 6（开发使用 6000.6.6），URP 渲染管线，开启 HDR 与后处理（泛光、ACES 色调映射、暗角）。
- **商业模式**：Steam 买断制（建议定价 30~70 元人民币），后续推出 DLC（新阵营、新篇章）。
- **无内购、无广告**。

## 2. 世界观与剧情

### 2.1 故事背景

2187 年，人类已在近地轨道建立太空电梯和空间站，但从未离开过月球轨道。

一天，月球背面的深空雷达收到一段重复的信号，人们称之为“回声”。三个月后，**蜂群**的先遣部队从天而降，地球各地的防线接连失守。

玩家扮演地球防卫军“晨星部队”的年轻指挥官，在 AI 副官诺娃的协助下，带领残存的部队展开反击。

### 2.2 势力

| 势力 | 身份 | 风格 |
|---|---|---|
| **晨星部队 / 星盟**（玩家） | 人类防卫军，后发展为人类星际联盟 | 均衡，重装甲、强护盾，可学习敌方科技 |
| **蜂群** | 机械智能集群，故事前期的主要敌人 | 数量庞大、廉价、可自我修复 |
| **虚空行者** | 古老的能量文明，宇宙篇登场 | 隐形、跃迁突袭、高爆发 |
| **寂灭** | 隐藏在银河核心的终极威胁，最终敌人 | 吞噬恒星的存在，后期揭晓 |

### 2.3 主要角色

| 角色 | 身份 | 作用 |
|---|---|---|
| 指挥官（玩家） | 晨星部队指挥官 | 主角，可自定义名字和头像 |
| 诺娃 | AI 副官 | 战术提示、教学引导、剧情主线人物（身世之谜） |
| 雷恩将军 | 地球防卫军老将 | 地球篇的导师，太阳系篇牺牲 |
| 林工 | 首席工程师 | 负责研发与改装，解锁新兵器时登场 |
| 卡西 | 王牌飞行员 | 战机部队队长，性格冲动，常在战斗中插话 |
| 维拉 | 虚空行者使者 | 宇宙篇登场，从敌人变为盟友 |

### 2.5 剧情的呈现方式

为控制成本，不做过场动画，采用以下方式：

| 方式 | 说明 | 用在哪里 |
|---|---|---|
| **立绘对话** | 角色半身立绘 + 对话框 | 每关开始前、结束后 |
| **战斗通讯** | 战斗中屏幕角落弹出角色头像和短句，不暂停游戏 | 关卡中的关键时刻 |
| **章节插画** | 一张全屏插画加旁白文字 | 每章开头和结尾 |
| **图鉴档案** | 敌人、兵器、地点的背景故事，收集后解锁 | 图鉴系统 |
| **可跳过** | 所有剧情都可以跳过，可在档案中重看 | 全部 |

## 3. 游戏结构

### 3.1 整体循环

```
            ┌──────────────────────────────────┐
            ▼                                  │
     【战役地图】选择关卡                         │
        │                                     │
        ├─▶ 主线关卡 ──▶ 剧情推进、解锁兵器、经验 ──┤
        ├─▶ 支线挑战 ──▶ 星星、图鉴、涂装 ─────────┤
        ├─▶ 远征 ─────▶ 经验、兵器、组件、资源 ────┤
        │                                     │
        ▼                                     │
     【母港】升级、改装、编队、图鉴 ───────────────┘
        │
        ▼
     达到层级等级上限 ──▶ 突破战（或选择停级）
```

### 3.2 每天 30 分钟

| 时间 | 内容 |
|---|---|
| 10 分钟 | 推进 2~3 个主线关卡，看剧情 |
| 15 分钟 | 一次远征 |
| 5 分钟 | 回母港升级、改装、看图鉴 |

### 3.3 等级与层级

| 层级 | 等级范围 | 战场 | 新增机制 |
|---|---|---|---|
| **地球级** | 1~30 | 地表、海洋、大气层、近地轨道 | 基础战斗、克制关系、补给点数 |
| **太阳系级** | 31~60 | 行星表面、卫星轨道、小行星带 | 引力井、短距跃迁、补给线 |
| **宇宙级** | 61~100 | 星系之间、星云、虫洞 | 威慑、阵营羁绊、超大规模舰队战 |

- **经验来源**：主线关卡（多）、远征（中）、支线挑战（少）。
- **节奏目标**：正常推进主线，加上每个区域 1~2 次远征，就能满足后续关卡的等级要求，**不需要专门刷级**。

### 3.4 突破与停级

**突破**

- 达到层级等级上限（30 / 60）后，主动开启“突破战”。
- 击败突破战 Boss 后进入下一层级，解锁新地图、新兵器、新机制。
- 等级到了**不会自动突破**，由玩家决定。

**停级**

停在当前层级，可以获得：

| 内容 | 说明 |
|---|---|
| 层级精通挑战 | 当前层级的“威胁等级 1~10”，每级给敌人加一条增强规则 |
| 极限养成 | 兵器可强化到当前层级的上限 |
| 层级专属奖励 | 精通挑战的称号、涂装、旗舰外观，只能在停级时通过精通挑战获得 |
| 层级图鉴 | 收集当前层级的全部兵器和档案 |

**回访**：突破后可以随时回到之前的层级打主线、支线和远征，补齐图鉴。但**层级精通挑战的专属奖励只能在停级时获得**，保留停级的意义。

## 4. 关卡设计

### 4.1 关卡数量

| 层级 | 章节 | 每章关卡 | 主线关卡 | 突破战 / 最终战 |
|---|---|---|---|---|
| 地球级 | 5 章 | 6 关 | 30 关 | 1 关 |
| 太阳系级 | 5 章 | 6 关 | 30 关 | 1 关 |
| 宇宙级 | 5 章 | 8 关 | 40 关 | 1 关 |
| **合计** | **15 章** | | **100 关** | **3 关** |

在此基础上：

- **困难模式**：通关某一章后解锁该章的困难版本（敌人更强、配置变化、新的支线目标），关卡数量翻倍到 **200 关**。
- **每关 3 颗星**：完成关卡得 1 星，完成两个支线目标各得 1 星，共 **600 颗星**可收集，星星用于解锁图鉴奖励。
- **远征**：随机生成，无限重玩。

每一章的结构：

```
关卡 1~2  ：引入本章新敌人或新机制
关卡 3~4  ：组合运用
关卡 5    ：特殊玩法关（护送、防守、生存等）
关卡 6    ：章节 Boss（宇宙级为关卡 8）
```

### 4.2 关卡类型

一百关不需要一百种全新设计，而是用以下**关卡模板**搭配不同地图、敌人配置和剧情：

| 类型 | 胜利条件 | 特点 |
|---|---|---|
| 歼灭 | 消灭全部敌人 | 最基础的类型 |
| 防守 | 在敌人波次进攻下坚守指定时间 | 布阵为主 |
| 护送 | 保护运输舰到达终点 | 需要分兵保护 |
| 突袭 | 在限定时间内摧毁指定目标 | 节奏快，考验路线选择 |
| 占领 | 占领并守住若干据点 | 补给站争夺 |
| 生存 | 在越来越强的敌人中存活 | 后期关卡 |
| 断补给 | 切断敌方补给线后决战 | 体现补给机制 |
| Boss | 击败巨型敌人 | 每章结尾，有多个阶段 |

### 4.3 支线挑战示例

- 不损失任何单位
- 只使用指定类型的兵器
- 在 X 分钟内获胜
- 不使用跃迁增援
- 至少击毁 X 个敌方补给单位
- 在被威慑状态下获胜

### 4.4 关卡制作方式

- 所有关卡都由**配置数据**驱动：地图、敌人部署、波次、胜利条件、剧情触发点。
- 开发 **Unity 关卡编辑器工具**，可视化摆放敌人和地图元素，导出配置文件。
- 地图素材**按章节复用**：同一章的 6~8 关共用一套场景素材，通过不同的地形布置和视角区分。

## 5. 战斗系统

### 5.1 基本规则：布阵 + 自动战斗

战斗采用**战前布阵、战斗自动进行**的方式（类似自走棋）。玩家的策略集中在布阵阶段：选兵、站位、组件搭配、克制针对。

```
【布阵阶段】关卡与远征不限时（实时对战限时，见 10.3）
  查看敌方阵容（规则见 5.1.2）→ 把兵器从编队拖到己方格子上 → 调整站位和扩展组件
       ↓
【战斗阶段】自动进行，1~2 分钟
  兵器按各自的 AI 自动索敌、移动、开火、释放技能
  可 1 倍 / 2 倍 / 4 倍速观看，或直接跳过看结果
       ↓
【结算】胜负、星级、战利品；失败可立即调整布阵重打
```

- **2.5D 战场**：单位在平面上移动，三维画面加斜俯视镜头。
- **单场战斗时长**：1~2 分钟（1 倍速）。

#### 5.1.1 布阵棋盘

- 己方半场**前排宽 8 格、纵深 6 格**（v0.9 起，原为 6 × 4），小型和中型兵器占 1 格，**大型兵器占 2 × 2 格**。
- **横向战场（侧面视角）**：我方在左、敌方在右，双方前排隔着中间的接触线相对；前排是一条从上到下 8 格长的线，纵深 6 格向左（我方）或向右（敌方）展开。
- 布阵界面：编队列表在左侧，棋盘在中间，棋盘下方是战力对比、补给网络说明和敌方情报，战前推演在最右侧。
- 补给节点放在**格子的交叉点**上，不占格子（见 16.3）。
- 可上阵数量受**指挥点上限**限制（见 7.2）。
- 站位的意义：

| 位置 | 适合 | 原因 |
|---|---|---|
| 前排（靠近接触线的一排） | 重型、护卫 | 先接敌，承受伤害 |
| 后排 | 战列舰、导弹、支援 | 射程远，需要保护 |
| 侧翼（前排的上下两端） | 战机、突击 | 速度快，绕后攻击对方后排 |

- 布阵可以保存为**阵容方案**，下次直接套用。

#### 5.1.2 能否看到敌方阵容

| 模式 | 布阵时能否看到敌方阵容 |
|---|---|
| 主线关卡 / 支线挑战 | **能看到**。关卡是“看阵容、找克制”的策略谜题 |
| 远征 | 普通节点能看到；少量“未知信号”节点看不到，制造惊喜 |
| 天梯挑战 | **能看到**对方的防守阵容（见 10.2） |
| 实时对战 | **看不到**，双方同时盲布阵（见 10.3） |

### 5.2 自动战斗规则

战斗中兵器完全由 AI 控制，行为由**固有属性**决定：

| 行为 | 说明 |
|---|---|
| 索敌偏好 | 每个兵器有固有的目标优先级。例如：战机优先攻击大型舰船；护卫舰优先攻击战机；战列舰优先攻击距离最近的目标 |
| 移动 | 向目标移动到射程内后停下开火；近程兵器会主动贴近 |
| 技能释放 | 固有技能和主动组件技能在条件满足时自动释放（例如“紧急维修”在结构值低于 40% 时释放） |
| 撤退 | 部分兵器有固有特性“受损后撤回补给范围” |

**指挥官技能（已确定保留）**

每场战斗携带 3 个**指挥官技能**，让玩家在自动战斗中也有少量参与：

- 例如：轨道打击（范围伤害）、紧急护盾（全体护盾）、跃迁增援（投入 1 个预备兵器）。
- 消耗**补给点数**，补给点数在战斗中随时间恢复。
- 不使用也能正常打完；天梯防守方由 AI 按固定规则释放。

### 5.3 补给（地球级起）

**局内补给点数**

- 战斗中随时间恢复，用于指挥官技能。
- 地图上的补给站被己方兵器占据时，恢复速度提高。

**补给范围（太阳系级起完整开放）**

- 补给舰、补给站周围有补给范围。**补给舰放在哪个格子**是布阵时的重要决策。
- 单位离开补给范围过久：导弹类弹药逐渐耗尽，护盾停止恢复。
- 击毁敌方支援单位、切断补给线是重要战术。

**远征中的补给**

- 每跳一个星区消耗燃料，战斗消耗弹药，受损单位需要修理。
- 补给不足时需要冒险选择路线，或者放弃受损单位。

### 5.4 威慑（宇宙级完整开放）

**局内威慑**

- **开战时**比较双方上阵阵容的战力；战斗中根据场上剩余兵力价值实时更新。
- 一方兵力价值超过对方 1.5 倍时，对方进入**被威慑状态**：射速下降 10%，占领速度下降。
- 弱势方击毁对方高价值单位时触发“士气爆发”：短时间伤害提升，并解除被威慑状态。

**远征中的威慑**

- 遭遇比自己弱很多的敌人时，可以选择“威慑”：敌人直接投降并交出部分物资，跳过战斗。
- 舰队越强，远征越顺畅，玩家能直接感受到成长。

### 5.5 克制关系

| 兵种 | 克制 | 被克制 |
|---|---|---|
| 战机群 | 大型舰船 | 防空单位 |
| 防空 / 护卫 | 战机群 | 导弹 / 鱼雷单位 |
| 导弹 / 鱼雷 | 护卫、中型单位 | 战机群 |
| 主力（巡洋 / 主战） | 导弹单位 | 重型单位 |
| 重型（战列 / 重型机甲） | 主力、护卫 | 战机群 |
| 支援 | — | 所有攻击单位 |

## 6. 兵器体系

### 6.1 各层级兵器

| 层级 | 数量 | 兵器示例 |
|---|---|---|
| **地球级** | 8 种 | 突击机甲、悬浮战车、防空车、导弹发射车、空天战机、重型机甲、工程支援车、指挥车 |
| **太阳系级** | 8 种 | 战机群、护卫舰、驱逐舰、巡洋舰、轨道炮台、补给舰、维修舰、旗舰“晨星号” |
| **宇宙级** | 10 种 | 战列舰、航母、隐形突击舰、电子战舰、无人机母舰、要塞舰，以及通过剧情获得的虚空行者和蜂群单位 |
| **合计** | **26 种** | |

**跨层级使用**：低层级兵器可以升级为高层级版本（例如“空天战机”升级为“宇宙战机群”），玩家培养的兵器不会作废。

### 6.2 固有属性

每个兵器都有一套**固有属性**，决定它的定位和基本玩法。**固有属性是兵器强弱和打法的主体**，扩展组件只在此基础上做补充（见 7.5）。

#### 6.2.1 固有属性组成

| 类别 | 属性 | 说明 |
|---|---|---|
| **定位** | 兵种、体型、武器类型、阵营、层级 | 决定克制关系和能装哪些组件，**不可被任何组件改变** |
| **生存** | 结构值、护盾值、护盾恢复速度、装甲类型（轻 / 中 / 重） | 装甲类型决定受到不同武器的伤害倍率 |
| **火力** | 伤害、射速、射程档位（近 / 中 / 远 / 超远）、攻击方式（单体 / 范围 / 持续） | 射程档位和攻击方式**不可被组件改变** |
| **机动** | 移动速度、转向速度 | |
| **补给** | 弹药容量、补给消耗速度、部署费用 | |
| **指挥** | 指挥点占用 | 编队时的占用值 |
| **固有技能** | 1 个兵器自带的主动技能，战斗中自动释放 | 体现该兵器最核心的特色 |
| **索敌偏好** | 优先攻击的目标类型 | 自动战斗中决定兵器打谁 |
| **固有特性** | 1~2 个被动特性 | 例如战列舰“重炮齐射：每第 5 次攻击造成双倍伤害”，战机“编队飞行：3 架以上同时行动时闪避提高” |

#### 6.2.2 固有属性的成长

固有属性通过**等级、升星、技能升级、进阶**提升（见 8.3），这是兵器变强的主要途径：

- **等级**：结构值、护盾、伤害按成长曲线提升。
- **升星**：属性大幅提升；3 星、5 星时**固有技能**获得新效果。
- **进阶**：跨层级升级时，固有属性整体跃升，并强化固有特性。

#### 6.2.3 兵器示例

| 兵器 | 定位 | 射程 | 攻击方式 | 固有技能 | 固有特性 |
|---|---|---|---|---|---|
| 空天战机 | 战机 / 小型 / 动能 | 近 | 单体 | 俯冲扫射：沿直线对地面目标造成伤害 | 编队飞行 |
| 导弹发射车 | 导弹 / 中型 / 导弹 | 远 | 范围 | 饱和齐射：一次性发射全部导弹 | 弹药有限，补给依赖高 |
| 驱逐舰 | 导弹 / 中型 / 导弹 | 中 | 单体高爆发 | 鱼雷突击：向前方发射鱼雷 | 对中大型目标伤害提高 |
| 战列舰 | 重型 / 大型 / 动能 | 超远 | 单体 | 主炮齐射：大威力远程炮击 | 重炮齐射 |
| 补给舰 | 支援 / 中型 / 无 | — | 无攻击 | 紧急补给：为范围内友军补满弹药 | 自身周围形成补给范围 |

### 6.3 稀有度

普通 → 稀有 → 史诗 → 传说。稀有度越高，**技能越特殊**，但基础数值不碾压低稀有度。

## 7. 养成系统

### 7.1 母港

母港是玩家的大本营，随剧情推进从地面基地升级为太空要塞。

| 设施 | 作用 |
|---|---|
| 指挥中心 | 选择关卡、查看战役地图 |
| 研发中心 | 用资源升级兵器 |
| 改装车间 | 安装和更换扩展组件 |
| 编队室 | 组建和保存编队 |
| 档案馆 | 图鉴、剧情回看、成就 |

母港设施本身也可以升级，解锁更多编队槽位、改装槽位、起始补给。

### 7.2 编队

- 每支编队：**1 个指挥单位 + 最多 8 个兵器**。
- **指挥点上限**：所有兵器的指挥点之和不能超过上限，上限随等级提升。

### 7.3 升级与改装

| 方式 | 效果 |
|---|---|
| 升级 | 提升基础属性，上限受当前层级限制 |
| 扩展组件 | 每个兵器 3 个扩展槽，安装小组件，在固有属性基础上做补充（见 7.5） |
| 涂装 | 纯外观 |

升级所需的材料全部来自关卡战利品，详细规则见第 8 节。

### 7.4 羁绊

编队中满足条件时激活加成，鼓励尝试不同组合：

| 羁绊示例 | 条件 | 效果 |
|---|---|---|
| 钢铁洪流 | 3 个重型单位 | 全体装甲提升 |
| 制空权 | 3 个战机单位 | 战机出击速度提升 |
| 后勤保障 | 2 个支援单位 | 补给范围扩大 |
| 蜂群同化（宇宙级） | 3 个蜂群单位 | 被击毁的单位有几率重生 |
| 虚空共鸣（宇宙级） | 2 个虚空行者单位 | 跃迁冷却缩短 |

首发计划 **8~10 种羁绊**。

### 7.5 扩展槽与小组件

每个兵器有 **3 个扩展槽**，可以安装**小组件**。小组件是对兵器的**扩展和补充**：可以强化兵器的长处、弥补短处，或者增加一个辅助技能，但**不能改变兵器的大致玩法**。兵器的定位和主要战斗力来自固有属性（见 6.2）。

#### 7.5.1 扩展槽

| 扩展槽 | 可安装 | 解锁条件 |
|---|---|---|
| 槽 1：主动槽 | 主动组件 | 获得兵器时开放 |
| 槽 2：被动槽 | 被动组件 | 兵器升到 2 星 |
| 槽 3：被动槽 | 被动组件 | 兵器升到 4 星 |

- 每个兵器最多 **2 个主动技能**：1 个固有技能 + 1 个主动组件技能，战斗中都自动释放。
- 扩展槽的解锁和升星挂钩，升星除了提升固有属性，还能开放更多补充手段。

#### 7.5.2 组件类型

**主动组件**：战斗中满足条件时自动释放，有冷却时间。

| 组件 | 效果 | 适合 |
|---|---|---|
| 护盾过载 | 3 秒内护盾吸收量翻倍 | 重型、前排 |
| 紧急维修 | 立即恢复 30% 结构值 | 所有 |
| 集束导弹 | 对目标区域造成范围伤害 | 导弹单位 |
| EMP 脉冲 | 周围敌人停火 2 秒 | 前排、突击 |
| 短距跃迁 | 瞬间移动到指定位置（太阳系级起） | 突击、战机 |
| 诱饵信标 | 放置信标，吸引敌人火力 4 秒 | 支援 |
| 隐形力场 | 自身及周围友军隐形 3 秒 | 突袭、侦察 |
| 补给投送 | 为附近友军立即补满弹药 | 支援 |

**被动组件**：安装后自动生效，分为常驻和触发两类。

| 组件 | 类型 | 效果 |
|---|---|---|
| 穿甲弹头 | 常驻 | 对重型单位伤害 +15% |
| 火控雷达 | 常驻 | 射程 +10% |
| 扩容弹舱 | 常驻 | 弹药容量 +30%，离开补给范围后坚持更久 |
| 节能引擎 | 常驻 | 移动速度 +10%，燃料消耗 -20%（远征中有效） |
| 威慑涂层 | 常驻 | 计算威慑时自身价值 +20% |
| 反应装甲 | 触发 | 每场战斗第一次受到致命伤害时保留 1 点结构值 |
| 连锁殉爆 | 触发 | 击毁敌人时对其周围敌人造成伤害 |
| 纳米修复 | 触发 | 在补给范围内每秒恢复 1% 结构值 |
| 复仇协议 | 触发 | 附近友军被击毁时，自身伤害提高 20%，持续 5 秒 |

#### 7.5.3 稀有度

| 稀有度 | 特点 |
|---|---|
| 普通 / 稀有 | 数值类效果（伤害、射程、速度） |
| 史诗 | 有机制变化（触发效果、范围效果） |
| 传说 | 独特机制，在兵器原有定位上提供强力补充，例如“黑洞发生器”：在战场制造引力井，把敌人吸向中心，配合战列舰的远程火力 |

#### 7.5.4 装配规则（双向限制）

**兵器规定自己能装哪些组件，组件也规定自己能装在哪些兵器上，两边条件都满足才能安装。**

**组件分类**

| 类别 | 说明 | 示例 |
|---|---|---|
| 武器类 | 增强现有攻击（伤害、射程、对特定目标的效果） | 集束导弹、穿甲弹头、火控雷达、连锁殉爆 |
| 防御类 | 生存能力 | 护盾过载、反应装甲、纳米修复 |
| 机动类 | 移动与位置 | 短距跃迁、节能引擎 |
| 支援类 | 帮助友军 | 补给投送、紧急维修、诱饵信标 |
| 电子类 | 干扰与隐蔽 | EMP 脉冲、隐形力场 |
| 特殊类 | 独特机制，多为传说组件 | 黑洞发生器、威慑涂层、复仇协议 |

**兵器标签**：每个兵器带有一组标签，用于组件判断能否安装。

| 标签维度 | 取值 |
|---|---|
| 兵种 | 战机、护卫、导弹、主力、重型、支援、指挥 |
| 体型 | 小型、中型、大型 |
| 武器类型 | 动能、能量、导弹、无人机 |
| 层级 | 地球级、太阳系级、宇宙级 |
| 阵营 | 晨星、蜂群、虚空行者 |

**第一层限制：兵器的扩展槽规定接受哪些组件类别**

| 兵器（示例） | 槽 1（主动） | 槽 2（被动） | 槽 3（被动） |
|---|---|---|---|
| 空天战机 | 武器类 / 机动类 | 武器类 / 机动类 | 电子类 / 特殊类 |
| 驱逐舰 | 武器类 / 电子类 | 武器类 | 机动类 / 防御类 |
| 战列舰 | 武器类 / 防御类 | 防御类 | 武器类 / 特殊类 |
| 补给舰 | 支援类 | 支援类 / 防御类 | 机动类 / 特殊类 |
| 隐形突击舰 | 电子类 / 机动类 | 武器类 | 电子类 / 特殊类 |

**第二层限制：组件规定适用的兵器标签**

| 组件（示例） | 类别 | 适用条件 |
|---|---|---|
| 集束导弹 | 武器类 | 武器类型为“导弹” |
| 穿甲弹头 | 武器类 | 武器类型为“动能” |
| 护盾过载 | 防御类 | 体型为中型或大型 |
| 短距跃迁 | 机动类 | 层级为太阳系级及以上，且体型为小型或中型 |
| 隐形力场 | 电子类 | 兵种为“战机”或“支援”，或带有“虚空行者”阵营标签 |
| 编队突击 | 武器类 | 仅限兵种“战机” |
| 黑洞发生器 | 特殊类 | 仅限体型“大型”，且层级为宇宙级 |
| 紧急维修 | 支援类 | 无限制（通用） |

**举例**：驱逐舰的槽 1 接受武器类，集束导弹属于武器类，而且驱逐舰的武器类型是导弹，两边都满足，可以安装。穿甲弹头也属于武器类，但驱逐舰不是动能武器，所以不能装。

**界面表现**

- 点开某个扩展槽时，只列出**可以安装**的组件；不能安装的显示为灰色，并说明原因（例如“需要：导弹类武器”）。
- 组件详情页显示“**可装备兵器**”的图标列表，玩家拿到新组件时立刻知道该给谁用。
- 图鉴中提供“兵器 × 组件”的适配总表。

**为什么要双向限制**

1. **兵器有个性**：战机就是灵活突袭，战列舰就是厚重火力，不会所有兵器都变成同一套最强搭配。
2. **平衡更容易**：限制了组合范围，强力组件只能出现在特定兵器上，避免出现无敌组合。
3. **收集有目标**：“我想要一个集束导弹给我的驱逐舰用”，玩家会有明确的刷取目标。

**防止限制过严的规则**

- 每个扩展槽至少接受 **2 个组件类别**。
- 每个组件至少适用于 **5 种以上兵器**（专属组件除外）。
- 保留少量**通用组件**（例如紧急维修），保证任何兵器在任何时候都有组件可装。
- 每个层级掉落的组件，至少有一半能用在该层级的主力兵器上，避免“掉了一堆用不上”。

**数据配置示例**

```json
{
  "id": "destroyer_mk1",
  "tags": ["导弹", "中型", "太阳系级", "晨星"],
  "slots": [
    { "type": "active",  "accepts": ["武器类", "电子类"] },
    { "type": "passive", "accepts": ["武器类"],           "unlockStar": 2 },
    { "type": "passive", "accepts": ["机动类", "防御类"], "unlockStar": 4 }
  ]
}
```

```json
{
  "id": "cluster_missile",
  "category": "武器类",
  "kind": "active",
  "requires": { "weaponType": ["导弹"] }
}
```

```json
{
  "id": "short_jump",
  "category": "机动类",
  "kind": "active",
  "requires": { "minTier": "太阳系级", "size": ["小型", "中型"] }
}
```

规则判断：`扩展槽.accepts 包含 组件.category` 并且 `兵器标签满足 组件.requires`。

#### 7.5.5 获取与强化

- **获取**：关卡和远征掉落（见 8.1），支线 3 星、困难模式、Boss 是稀有组件的主要来源。
- **强化**：+0 到 +10，消耗信用点和同类组件（见 8.3）。强化到 **+5 和 +10 时各获得一次额外效果**，例如“紧急维修 +10：恢复时同时清除负面状态”。
- **自由拆装**：组件可以随时卸下换到别的兵器上，**不损耗、不花费**，鼓励玩家多尝试搭配。

#### 7.5.6 设计原则

1. **固有属性为主，组件为辅**。兵器的定位、射程档位、攻击方式、克制关系由固有属性决定，任何组件都不能改变。组件只在原有玩法上做“微调”：
   - **强化长处**：驱逐舰本来就是鱼雷高爆发，装“穿透鱼雷”让爆发更集中。
   - **弥补短处**：驱逐舰怕战机，装“近防炮”能在战机面前多撑一会儿，但仍然打不过战机。
   - **增加辅助手段**：装一个主动组件，多一个应急技能。
   
   不管怎么装，驱逐舰始终是“中程、单体高爆发、怕战机”的驱逐舰。
2. **数值占比上限**：
   - 一个兵器的战力中，**固有属性（含等级、升星、进阶）约占 75% 以上，扩展组件合计不超过 25%**。
   - 单项属性的组件加成有上限，例如射程最多 +15%、移动速度最多 +15%、伤害最多 +25%，射程提升**不会跨越射程档位**。
   - 主动组件技能的效果和冷却都弱于兵器的固有技能，固有技能始终是核心技能。
3. **和核心机制联动**：扩容弹舱、补给投送、纳米修复与补给机制联动；威慑涂层与威慑机制联动。
4. **首发数量**：40 个组件，其中主动组件 12 个、被动组件 28 个（含 6 个传说组件）。

## 8. 战利品与装备强化

核心循环：**打关卡 → 掉落战利品 → 强化兵器 → 战力提升 → 挑战更难的关卡。**

### 8.1 战利品种类

| 类别 | 名称 | 用途 | 主要来源 |
|---|---|---|---|
| 通用货币 | 信用点 | 所有升级的基础费用、远征商店购买 | 所有关卡 |
| 基础材料 | 合金 | 兵器升级 | 所有关卡 |
| 基础材料 | 能源电池 | 技能升级 | 所有关卡 |
| 层级材料 | 稀土合金（地球级）/ 氦-3（太阳系级）/ 虚空晶体（宇宙级） | 兵器进阶、跨层级升级 | 对应层级的关卡 |
| 兵器碎片 | 各兵器专属碎片 | 解锁新兵器、兵器升星 | 指定关卡、Boss、远征精英 |
| 扩展组件 | 主动组件 / 被动组件 | 安装到兵器扩展槽 | 支线 3 星、困难模式、远征 |
| 收集品 | 涂装、档案 | 外观与剧情 | 星星奖励、Boss、隐藏目标 |

### 8.2 掉落规则

| 情况 | 掉落内容 |
|---|---|
| **首次通关** | 固定的大量奖励，通常包含新兵器或兵器碎片 |
| **重复挑战** | 随机掉落，数量较少，但可以无限次挑战（没有体力限制） |
| **星级加成** | 关卡达到 3 星后，重复挑战掉落数量提高 50% |
| **章节 Boss** | 必定掉落稀有以上的兵器碎片或扩展组件 |
| **困难模式** | 掉落普通模式没有的稀有组件和兵器变体 |
| **远征** | 掉落数量最多、种类最随机，是刷材料的主要途径 |

**掉落预览**：每个关卡在进入前展示可能掉落的物品，玩家可以针对性地去打某一关，收集自己需要的材料。

**保底机制**：稀有物品连续若干次没有掉落时，下一次必定掉落，避免运气太差。

**设计原则**：正常推进主线就能获得足够的材料跟上关卡难度；刷材料是为了“更强”和“更快”，不是“必须”。

### 8.3 兵器强化方式

| 方式 | 消耗 | 效果 | 上限 |
|---|---|---|---|
| **等级升级** | 信用点 + 合金 | 结构值、护盾、伤害按等级成长 | 不超过指挥官当前等级 |
| **升星**（1~5 星） | 兵器碎片 | 每升一星属性大幅提升；3 星、5 星时技能获得新效果 | 5 星 |
| **技能升级** | 能源电池 | 技能伤害提高、冷却缩短 | 技能 10 级 |
| **进阶** | 层级材料 | 低层级兵器升级为高层级版本（如“空天战机”进阶为“宇宙战机群”），解锁新外观和新技能 | 每个层级一次 |
| **组件强化** | 信用点 + 同类组件 | 组件效果从 +0 强化到 +10 | +10 |

**停级的联系**：等级升级上限受指挥官等级限制，停级的玩家可以把升星、技能、组件强化做到满，打造“同等级最强”的编队，挑战层级精通。

### 8.4 战力

**单个兵器战力**由固有属性（等级、星级、技能等级、进阶）和扩展组件综合计算，其中固有属性约占 75% 以上，组件不超过 25%（见 7.5.6）。界面上用一个数字表示。

**编队战力** = 所有兵器战力之和 + 羁绊加成。

战力在游戏中的作用：

| 用途 | 说明 |
|---|---|
| 推荐战力 | 每个关卡显示推荐战力，编队战力低于推荐值时提示风险 |
| 远征威慑 | 编队战力远高于敌人时，可以直接威慑敌人投降（见 5.4） |
| 成长反馈 | 每次强化后显示战力提升数字和动画，让玩家直接感受到变强 |
| 图鉴成就 | 编队战力达到一定数值解锁称号和涂装 |

**策略仍然重要**：
- 战力只是参考，**合理的布阵和克制可以战胜高出 20% 左右战力的敌人**。
- 很多支线挑战星（例如“不损失单位”）需要靠战术完成，单纯堆战力拿不到。
- 敌人强度按关卡固定，不会随玩家战力变强，所以强化的效果能真实地体现出来。

### 8.5 数值平衡方向

- 每个层级内，满级满星编队的战力大约是刚进入该层级时的 **3 倍**，让成长感明显。
- 新层级的第一关敌人强度高于上一层级满强化的编队，但突破后获得的新兵器和进阶能快速追上，避免“突破后反而打不过”的挫败感。
- 具体数值在 P1 原型阶段，通过战斗内核的批量模拟测试来调整（见 11.2）。

## 9. 远征模式（Roguelite）

### 9.1 流程

```
选择编队出发
   ↓
随机星图（6~8 个节点，多条路线）
   ├─ 战斗：普通敌人
   ├─ 精英：更强敌人，掉落稀有兵器
   ├─ 事件：剧情选择题（救援、遗迹、谈判、交易）
   ├─ 商店 / 船坞：购买、修理、改装
   └─ 终点 Boss
   ↓
结算：带回经验、兵器、组件、资源
```

- 一次远征 15~20 分钟，中途可以存档退出。
- 远征失败也能带回部分资源，不会白打。
- 每个层级有自己的远征地图和敌人池。

### 9.2 远征内的成长

- 远征中获得的临时强化（例如“本次远征所有战机射速 +20%”）只在本次远征有效。
- 鼓励每次尝试不同的流派。

### 9.3 难度阶梯

- 每个层级的远征都有“威胁等级 1~10”（即停级精通挑战，见 3.4）。
- 通关后解锁“无尽星海”：不断深入的无限远征，记录最远距离。

### 9.4 每日星域（可选）

- 每天一张固定种子的星图，全球玩家相同，可上传分数参加排行榜。
- **完全可选，不玩没有任何损失**，没有登录奖励。需要联网，但不影响单机游玩。

## 10. 在线玩法：天梯与实时对战

在线玩法是**可选**的。不联网也能完整游玩全部单机内容；在线玩法给喜欢和其他玩家比较的人提供长期目标。

### 10.1 层级分榜

天梯和实时对战**按层级分别排名**：地球级榜、太阳系级榜、宇宙级榜。

- 玩家只能进入自己当前层级的榜单。
- **停级的意义因此进一步加强**：停在地球级的玩家，可以把阵容练到极致，在地球级榜单上称霸（类似《梦幻西游》的停级比赛）。

### 10.2 天梯挑战（异步对战）

**规则**

- 每个玩家设置一套**防守阵容**，上传到服务器。
- 天梯是一个**名次列表**。玩家可以查看排名在自己之前一定范围内（例如前 10 名以内）的玩家，**看到对方的防守阵容**，选择一位发起挑战。
- 战斗由双方阵容自动进行。**挑战成功则双方名次互换**；挑战失败名次不变。
- 被挑战的玩家不需要在线。上线后可以查看**防守记录**和战斗回放，并对击败自己的玩家发起“复仇”挑战。

**防守方**

- 防守阵容由 AI 按固定规则释放技能和指挥官技能。
- 防守阵容随时可以修改，修改后立即生效。

**节奏与奖励**

- **不设每日挑战次数和体力**，同一对手有短暂冷却（例如 10 分钟），防止反复刷同一人。
- 奖励按**赛季**（例如每 4 周）结算：根据赛季结束时的名次发放称号、涂装、头像框等**外观类奖励**，不发放影响战力的物品。
- 没有每日结算，不玩也不会被惩罚，只是名次可能被别人换走。

**公平性**

- 天梯使用玩家**实际的养成数据**，收集和强化的成果在这里体现。
- 本游戏为买断制、无内购，不存在“付费买战力”的问题。
- 按层级分榜，避免高层级玩家碾压低层级玩家。

### 10.3 实时对战（同步对战）

**规则**

- 匹配到同层级、相近积分的对手。
- 双方**同时盲布阵**，限时 60 秒，**互相看不到对方阵容**。
- 时间到后自动开战，双方观看同一场战斗。
- 采用**三局两胜**：每局结束后双方可以在 30 秒内调整布阵（仍然看不到对方的新布阵，但能看到上一局对方的阵容），增加读心博弈。

**为什么适合本游戏**

- 战斗是自动的，“实时对战”只需要同步双方的布阵，**不需要高频网络同步**，技术难度远低于即时战略游戏。
- 服务器用同一个确定性战斗内核计算结果，双方客户端播放相同的战斗。

### 10.4 防作弊

单机存档保存在本地，可能被修改。在线玩法采用以下措施：

- **在线养成数据以服务器为准**：参与在线玩法的账号，其兵器、组件、等级数据同步到服务器，并做合理性校验（例如等级不能超过层级上限、强化消耗与掉落记录匹配）。
- **战斗由服务器计算**：天梯和实时对战的结果由服务器运行确定性战斗内核得出，客户端只负责播放。
- 发现异常数据的账号不能进入在线榜单，但不影响其单机游玩。

## 11. 技术架构

### 11.1 总体结构

单机内容不需要服务器。在线玩法（第 10 节）需要一个轻量的游戏服务器；每日星域的排行榜可以直接使用 Steam 自带的排行榜功能。

```
Unity 客户端
├── 表现层：场景、单位、特效、UI、剧情对话
├── 游戏流程层：战役地图、母港、远征、存档
└── 战斗内核（纯 C# 类库，不依赖 Unity）
    ├── 单位、武器、技能
    ├── 补给、威慑
    ├── AI（行为树）
    └── 确定性随机数

游戏服务器（在线玩法，后期开发）
├── 账号（Steam 登录）与在线养成数据
├── 天梯名次、防守阵容、战斗记录
├── 实时对战匹配与布阵同步
└── 战斗内核（与客户端同一份代码，服务端计算结果）
```

### 11.2 关键技术决策

| 决策 | 理由 |
|---|---|
| 战斗内核与 Unity 分离 | 便于写自动化测试和平衡性测试（无界面批量模拟战斗） |
| 确定性随机数 + 固定种子 | 远征可复现，便于调试；每日星域需要所有玩家结果一致；在线对战由服务器计算，客户端回放结果一致 |
| 服务端技术 | C# / ASP.NET Core + PostgreSQL，与客户端共用战斗内核代码 |
| 数据驱动 | 兵器、关卡、剧情、远征事件全部用配置文件描述，方便调整和扩充内容 |
| 本地存档 + Steam 云存档 | 换电脑可以继续游戏 |
| 自研关卡编辑器 | 100 关以上的关卡制作需要高效工具 |

### 11.3 数据文件

```
data/
├── units/          兵器属性、技能
├── components/     扩展组件
├── loot/           掉落表、材料、强化消耗与成长曲线
├── synergies/      羁绊
├── levels/         关卡配置（按章节）
├── story/          剧情对话脚本
├── expedition/     远征节点、事件、敌人池
└── localization/   多语言文本（中文、英文起步）
```

### 11.4 代码仓库结构

```
XFramework/（仓库）
├── docs/                             设计文档
├── Starline/                         Unity 工程
│   └── Packages/com.starline.game/   游戏代码：Runtime/Battle（战斗内核）、Runtime/Client（客户端）
├── src/Starline.Battle/              用 .NET 编译战斗内核
├── tests/Starline.Battle.Tests/      内核测试、平衡性模拟
└── data/                             游戏数据配置（计划）
```

## 16. v0.9 新增：Roguelite 结构、展现方式与创新玩法

### 16.1 核心结构：一局远征

流程图见 [prototype/RunFlow.png](prototype/RunFlow.png)。

```
开局（选指挥官、初始 3 个兵器、1 个指挥官技能）
  → 第一幕 地球级（5~6 个节点）→ 突破战：月面要塞
  → 第二幕 太阳系级（5~6 个节点）→ 突破战：太阳系之门
  → 第三幕 宇宙级（5~6 个节点）→ 最终战：寂灭之心
  → 远征结算
```

- **一局 25~30 分钟**，每幕 8~10 分钟。每一局都完整体验一次“从地球打到宇宙”。
- **节点**：普通战斗、精英战、玩家阵容（其他玩家同一幕的真实阵容，离线时换成 AI 阵容）、事件、商店、补给站。
- **战斗循环**：星图选节点 → 布阵（可看到敌方阵容）→ 战前推演（可选）→ 自动战斗 20~40 秒 → 胜利则战利品三选一（兵器 / 扩展组件 / 指挥官技能）→ 整备（3 个同名兵器合成升星、装组件、调编队）。
- **舰队耐久**：共 5 点，战斗失败扣 1 点（Boss 战扣 2 点），归零则本局结束。
- **局外轻成长**：结算 → 新兵器和新组件加入奖池、解锁新指挥官 → 图鉴与成就 → 难度阶梯（替代原“停级”）。
- **原设定的对应关系**：

| 原设定 | 新结构中的位置 |
|---|---|
| 地球级 → 太阳系级 → 宇宙级、突破 | 一局中的三幕，每幕结尾是突破战 |
| 收集兵器、组件 | 局内收集（三选一、商店）+ 局外解锁奖池与图鉴 |
| 升级装备 | 局内合成升星、强化组件 |
| 停级 | 难度阶梯（威胁等级） |
| 天梯“看别人阵容挑战” | 远征中的“玩家阵容”节点（异步对战） |
| 剧情 | 每次结算解锁剧情片段，后续可加独立剧情模式 |

### 16.2 展现方式

- **2D 界面 + 3D 战斗**：母港、星图、商店、三选一、图鉴等用 2D 界面；布阵和战斗在 3D 场景中进行。
- **3D 风格**：低多边形模型，固定镜头，不需要玩家控制镜头。
- **侧面横向视角**：我方在左、敌方在右，适合 16:9 横屏，画面像横版战争电影。
- **布阵到开战的镜头过渡**：布阵时镜头接近正俯视（同样我方在左），格子清晰；点“开战”后镜头压低，转为从侧前方斜看的角度，舰队从左向右推进交火。
- **关键时刻特写**：释放指挥官技能、Boss 大招、大型兵器被击毁、补给线被切断时，自动给几秒特写再切回默认视角；可在设置中关闭，4 倍速和跳过时不播放。
- **兵器尽量不需要骨骼动画**：飞船、悬浮机甲、坦克、战车、飞机类单位只需移动、转向、开火，降低美术成本。
- **特效是爽感的主要来源**：激光、护盾受击、跃迁、爆炸用粒子系统重点打磨；HDR 泛光让激光、补给线和爆炸发光。
- 前期可使用 Unity 资源商店中的低多边形科幻素材，后期替换为原创设计。

### 16.3 创新玩法一：补给网络（核心玩法）

原型图见 [prototype/Formation2.png](prototype/Formation2.png)。

**规则**

- 布阵区**前排宽 8 格、纵深 6 格**。兵器占格子；**补给网络在另一层：补给节点放在格子的交叉点上，补给线沿着格线走，不占用兵器的格子。**
- 每场战斗己方阵地后方有一个固定的**补给源**（补给母舰，大型单位，占 2 × 2 格），它边上的一个交叉点是补给口。
- 布阵时可以在交叉点上放置**中继站**，每个消耗 1 指挥点。
- 两个节点在同一条格线上、相距不超过 **3 格**时，自动连成补给线。
- 每个节点**覆盖周围 2 格**，也就是以交叉点为中心的 4 × 4 格区域。
- 兵器有任意一格处于覆盖范围内，并且这个范围所属的节点能沿补给线连回补给源，就算**接入补给网络**。
- 战斗中补给线可以被切断：节点被击毁，或者补给线被敌方单位“压线”一段时间（例如 3 秒）。

**接入与未接入的区别**

| 状态 | 弹药 | 护盾恢复 | 技能 |
|---|---|---|---|
| 接入补给网络 | 持续补充 | 正常 | 正常冷却 |
| 未接入 | 只有初始携带量，打完就停火（导弹类影响最大） | 停止 | 冷却变慢 50% |

- **机动单位例外**：战机等机动单位有固有特性“短时离网”，离开补给网络后 10 秒内不受影响，适合执行切断敌方补给线的任务。

**带来的策略**

- 阵型紧凑，补给容易覆盖，但容易被范围攻击一起打中；阵型分散，需要更多补给节点。
- 进攻：派战机绕后切断敌方补给线，敌方导弹单位打光弹药后就失去威胁。
- 防守：在补给线附近放防空单位保护节点。
- 敌方（蜂群）同样有补给网络（补给虫巢），布阵时可以看到，并提前规划切断路线。

**和原设计的关系**：替代原来的“补给范围”（5.3）。局外的燃料补给（跳节点消耗燃料）保留。

### 16.4 创新玩法二：战前推演（招牌功能）

**规则**

- 布阵完成后，点击“战前推演”，消耗 1 点**情报点**，战斗内核在后台用不同随机种子**模拟 100 次**，几秒钟出结果。
- 推演结果包括：

| 内容 | 示例 |
|---|---|
| 胜率 | 62% |
| 平均用时、预计损失 | 34 秒；平均损失 2.1 个兵器 |
| 常见败因 | “左翼被飞蝗群突破（出现在 71% 的失败中）” |
| 关键事件 | “补给线 B 在 18 秒左右被切断（44%）” |
| 参谋建议 | “在第 1 排增加一个防空单位” |
| 推演记录 | 本场每次推演的胜率变化，例如 48% → 62% |

**限制（保证真实战斗仍有悬念）**

- 情报点有限：每局开始有 3 点，可在事件、商店中获得更多。
- 敌方部分单位带有**隐藏特性**，推演时按默认值计算，因此推演胜率有误差（例如 ±8%），界面上明确显示误差范围。
- 可以购买或获得“侦察”，揭示隐藏特性，缩小误差。
- 推演不消耗时间，不改变战斗结果的随机种子：真实战斗使用一个推演中没有用过的种子。

**技术实现**

- 战斗内核是确定性的纯 C# 代码，可以无界面运行，在后台线程批量模拟。
- 单场 20~40 秒的战斗按 20 帧每秒计算约 400~800 帧，100 次模拟在普通电脑上预计 1~3 秒内完成（P1 阶段实测确认）。

**宣传点**：“开战前，你的参谋已经推演了一百场战争。”

### 16.5 创新玩法三：缴获与实验室（逆向工程）

原型图见 [prototype/Lab.png](prototype/Lab.png)。

**缴获残骸（局内）**

- 击毁敌方单位时有概率留下该单位的**残骸**，战斗胜利后自动回收。精英敌人掉落概率更高，Boss 必定掉落专属残骸。
- 远征结束时，本局回收的残骸全部带回母港；远征失败也能带回一半。

**实验室（局外，母港中的新模块）**

- 在实验室中用残骸**发起逆向研究**，每个研究项目需要一定数量的同类残骸（例如飞蝗群残骸 ×3）。
- **研究时间：现实时间为主，实战缩短为辅**

**基础研究时间（现实时间）**

| 研究对象 | 基础时间 |
|---|---|
| 普通敌人 | 12 小时 |
| 精英敌人 | 18 小时 |
| Boss 专属武器 | 48 小时 |

- 研究开始后按现实时间倒计时，**关闭游戏也会继续计时**。
- 研究完成后成果一直保留，等玩家上线领取，**不会过期，也没有任何惩罚**。

**实战缩短（随剧情解锁）**

打仗可以缩短**所有进行中的研究**的剩余时间。这个能力随剧情逐步开放：

| 解锁时机 | 剧情 | 效果 |
|---|---|---|
| 首次击败第一幕突破战“月面要塞” | 林工从要塞残骸中带回第一批蜂群样本，**实验室开放** | 只有现实时间倒计时 |
| 首次击败第二幕突破战“太阳系之门” | 林工接入舰队的战斗数据链，“实战数据能帮我们看懂它们的结构” | 赢一场战斗 **−1 小时**；击败突破战 Boss **−3 小时**；完成一局远征（无论胜负）**−2 小时** |
| 首次通关最终战“寂灭之心” | 诺娃协助解析远古技术，实验室升级为“量子分析中心” | 以上缩短效果**翻倍**，并增加 1 个研究槽 |

- 每天玩 30 分钟左右（一局远征），在第二阶段大约能缩短 10~20 小时，基本能当天完成一个普通研究；不玩游戏时研究也照常按现实时间完成。
- **加速**：额外消耗 1 个同类残骸，剩余时间 −2 小时。
- 以上时间均为初始设定，在测试中根据玩家节奏调整。

**研究阶段与成果**

每个项目分阶段给奖励，不用等到 100% 才有收获：

| 进度 | 成果 |
|---|---|
| 25% | **揭示该敌人的隐藏特性**：以后战前推演对这种敌人不再有误差 |
| 60% | 获得该敌人武器的**扩展组件图纸**，组件加入奖池 |
| 100% | **逆向成功**：该敌方兵器加入己方奖池和图鉴，以后的远征中可以在三选一和商店里获得 |

- 逆向研究**不会失败**，避免挫败感。
- Boss 的研究成果是 Boss 专属武器（传说级扩展组件），例如“沙丘巨像”的“震荡核心”。

**研究槽与实验室升级**

- 初始 2 个研究槽，最多 4 个。
- 用信用点和稀有残骸升级实验室，增加研究槽、提高研究速度。

**研究树**

- 按敌方阵营分为“蜂群科技”“虚空科技”等分支，前一个项目完成后解锁后一个，例如：飞蝗群 → 酸液炮台 → 母体。
- 研究树也是局外长期目标的一部分，和图鉴一起提供收集感。

**和其他玩法的联动**

- **战前推演**：研究到 25% 就能消除对应敌人的推演误差，研究越多，推演越准。
- **剧情**：人类正是通过逆向蜂群残骸，才造出了第一艘宇宙战舰“晨星号”。实验室的首席研究员由林工担任，实验室的每次升级都对应一段剧情，研究完成时也有角色对话。
- **优先级**：在补给网络和战前推演验证好玩之后再加入。
