> 版本：v2.0
> 日期：2026-10-19
> 类型：单机科幻战略 / 布阵自动战斗 / Roguelite 远征 / 收集解锁
> 平台：PC（Steam）首发
> 代码仓库代号：XFramework

## 1. 概述

### 1.1 一句话介绍

**蜂群切断了连接人类殖民地的超空间航线“星线”。你指挥晨星舰队，一段一段重新点亮星线：战前排兵布阵、铺设补给网络，开战前先推演一百场战争，然后看舰队自动交火。**

### 1.2 设计目标

| 目标 | 具体要求 |
|---|---|
| 单机为主、不打卡 | 没有每日任务和体力；在线功能都是可选的 |
| 每天 30 分钟玩得完整 | 一局远征 25~30 分钟；常驻玩法一层 1~2 分钟 |
| 策略在布阵 | 选舰、站位、补给网络、克制；战斗自动进行，只保留少量指挥官技能 |
| 有辨识度 | 补给网络和战前推演是同类游戏没有的核心机制 |
| 长期吸引 | 每局不同的远征、难度阶梯、解锁与图鉴、实验室研究、无尽的信标链 |

### 1.3 参考游戏

| 游戏 | 借鉴点 |
|---|---|
| 背包乱斗 / Mechabellum | 布阵自动战斗、异步对战其他玩家的阵容 |
| 杀戮尖塔 | 随机路线、难度阶梯 |
| FTL：超越光速 | 太空远征、资源和补给管理 |
| 云顶之弈 / 自走棋 | 合成升星、阵容搭配 |

### 1.4 平台与商业模式

- **平台**：PC（Steam）首发；以后可考虑移植手机或微信小游戏。
- **引擎**：Unity 6（开发使用 6000.6.6），URP 渲染管线，HDR 与后处理。
- **商业模式**：Steam 买断制（建议 30~70 元人民币），后续 DLC（新阵营、新星区）。无内购、无广告。
- **发行策略**：第一幕完成后上 Steam 抢先体验，边卖边做后两幕。

## 2. 世界观与剧情

### 2.1 背景

星历 412 年，人类分布在银河中两百多个殖民星上。把它们连在一起的，是一条由数千座超空间中继信标组成的航线，人们叫它**“星线”**。补给、能源、通信，全靠星线传递。

一天，银河核心方向涌出了**蜂群**。它们以信标的能量为食，一夜之间把星线啃成了碎片。这一天后来被称为“断线日”。失去补给的殖民地一个接一个陷落。

星线最末端的边境基地“灯塔站”幸存了下来。玩家是驻守在这里的**晨星舰队**指挥官，任务是：**沿着星线一段段打回去，修复信标，把孤立的殖民地重新连起来。**

**核心主题**：补给线就是生命线。战斗里你在布置补给网络，剧情里你在重建整个银河的补给网络。宣传语：“补给不断，人类不灭。”

### 2.2 势力

| 势力 | 身份 | 风格 |
|---|---|---|
| **晨星舰队**（玩家） | 灯塔站的人类舰队 | 均衡，依赖补给网络；能逆向敌方科技 |
| **蜂群** | 以信标能量为食的机械生物集群 | 数量多、生物外形；也有自己的“巢链”补给网络 |
| **虚空行者** | 古老的能量文明，第三幕登场 | 隐形、跃迁突袭；从敌人变为盟友 |

### 2.3 主要角色

| 角色 | 身份 | 作用 |
|---|---|---|
| 指挥官（玩家） | 晨星舰队指挥官 | 主角 |
| 诺娃 | 舰队 AI 副官 | 战前推演的“参谋”；身世是剧情主线之谜 |
| 雷恩舰长 | 老兵，灯塔站守备司令 | 第一、二幕的导师，第二幕为守住信标牺牲 |
| 林工 | 首席工程师 | 负责实验室和逆向研究 |
| 卡西 | 王牌舰载机飞行员 | 擅长切断敌方补给线，战斗中常有通讯 |
| 维拉 | 虚空行者使者 | 第三幕登场，揭示星线的真相 |

### 2.4 三幕剧情（一局远征的三幕）

| 幕 | 区域 | 剧情 | 幕末 Boss |
|---|---|---|---|
| 第一幕 | **边境星区** | 从灯塔站出发，夺回第一批信标，连通三个边境殖民地 | **残骸要塞**：蜂群用旧星线残骸堆成的要塞 |
| 第二幕 | **星团腹地** | 连通被围困的殖民星；发现蜂群在吞食信标能量并不断变强；雷恩舰长为守住信标牺牲 | **吞噬者**：吞下了一整座信标枢纽的巨型蜂群 |
| 第三幕 | **银河核心** | 与虚空行者从交战到结盟，得知星线最初是为了封印蜂群而建；诺娃是星线建造者留下的 AI 碎片 | **蜂群主脑**：盘踞在星线起点“零号信标” |

- 每次远征都完整打一遍三幕。
- **剧情按进度解锁**：首次到达某一幕、首次击败某个 Boss、累计完成远征次数，都会解锁新的剧情片段。通关后解锁“难度阶梯”和后续剧情。

### 2.5 剧情呈现

| 方式 | 用在哪里 |
|---|---|
| 立绘对话 | 每幕开始、Boss 战前后、远征结算 |
| 战斗通讯 | 战斗中屏幕角落弹出角色头像和短句，不暂停 |
| 事件节点 | 远征中的剧情选择题 |
| 档案 | 敌人、舰船、信标、殖民地的背景故事，在图鉴中解锁 |

所有剧情都可以跳过，并能在档案馆重看。

## 3. 游戏结构

| 模式 | 节奏 | 作用 |
|---|---|---|
| **主线远征**（第 4 节） | 一局 25~30 分钟 | 主体验：剧情、解锁新舰船和组件 |
| **深空信标链**（第 11 节） | 一层 1~2 分钟 | 常驻休闲：碎片时间玩几层，长期目标是走得更远 |
| **实验室**（第 10 节） | 局外 | 用缴获的残骸逆向研究敌方科技 |
| 在线玩法（第 12 节，可选） | — | 异步挑战其他玩家阵容、排行榜 |

**每天 30 分钟**：一局远征；或者打几层信标链，再去实验室领研究成果。

## 4. 主线远征（Roguelite）

流程图见 [prototype/RunFlow.png](prototype/RunFlow.png)。

### 4.1 一局的流程

```
开局：选指挥官，带 3 艘初始舰船和 1 个指挥官技能
  → 第一幕 边境星区（5~6 个节点）→ Boss：残骸要塞
  → 第二幕 星团腹地（5~6 个节点）→ Boss：吞噬者
  → 第三幕 银河核心（5~6 个节点）→ Boss：蜂群主脑
  → 结算
```

### 4.2 星图节点

| 节点 | 内容 |
|---|---|
| 普通战斗 | 常规敌人，胜利后战利品三选一 |
| 精英战 | 更强的敌人，掉落稀有舰船或组件，残骸掉率更高 |
| 玩家阵容 | 其他玩家在同一幕的真实阵容（异步对战，离线时换成 AI 阵容） |
| 事件 | 剧情选择题：救援殖民船、调查信标遗迹、和走私者交易等 |
| 商店 | 用信用点购买舰船、组件、指挥官技能 |
| 补给站 | 二选一：恢复 1 点舰队耐久，或领取 1 个中继信标（P3 加入燃料） |

每次在星图上有 2~3 条路线可选。

### 4.3 战斗循环

```
选节点 → 布阵（可看到敌方阵容）→ 战前推演（可选）→ 自动战斗 20~40 秒
  → 胜利：战利品三选一（舰船 / 扩展组件 / 指挥官技能）→ 整备 → 下一个节点
  → 失败：舰队耐久 −1，没有奖励，跳过这个节点回到星图（Boss 战失败 −2，可以重打）
```

### 4.4 局内资源

| 资源 | 规则 |
|---|---|
| 舰队耐久 | 共 5 点；战斗失败 −1，Boss 战失败 −2；归零则本局结束 |
| 信用点 | 战斗获得，商店消费（P3） |
| 燃料 | 每跳一个节点消耗；不足时舰船弹药上限降低，需要去补给站（P3） |
| 指挥点上限 | 第一幕从 12 开始，每过一个战斗节点 +2（输赢都算，避免一场失败滚雪球），最高 24；之后每幕提高起点 |
| 情报点 | 每场战斗 3 点，用于战前推演 |

### 4.5 局内成长

- **合成升星**：3 艘同名同星舰船自动合成 1 艘高一星的（最高 3 星）。★2 耐久（结构、护盾、护盾恢复）×1.6、伤害 ×1.5；★3 耐久 ×2.5、伤害 ×2.2。合成后的舰船接替原来的上阵位置。
- **舰船不会永久损失**：战斗中被击毁的舰船战后全部修复，失败的代价是舰队耐久。
- **扩展组件**：装到舰船的扩展槽上（见 8.3）。
- **指挥官技能**：最多带 3 个。

### 4.6 局外成长（轻量）

- 新舰船、新组件、新指挥官、新指挥官技能**加入奖池**（不是直接变强）。
- 图鉴、成就、涂装。
- **难度阶梯**：通关后解锁“威胁等级 1~20”，每级给敌人加一条规则。
- 实验室研究成果（第 10 节）。

### 4.7 第一幕的实现（P2）

已在代码中实现，数值由自动玩家批量模拟校准（`tests/Starline.Battle.Tests`）。

| 项目 | 内容 |
|---|---|
| 开局舰队 | 补给母舰、2 个中继信标、战列舰 / 护卫舰 / 导弹舰各 1 艘（共 10 指挥点） |
| 星图 | 6 层：战斗 ×2 → 战斗、战斗、补给 → 战斗、精英、补给 → 战斗 ×2、精英 → 补给、战斗 → Boss；每层顺序随机，节点连向下一层相邻的 1~2 个节点 |
| 敌方阵容 | 按层分三档：巡逻虫群、飞蝗骚扰 → 炮巢阵地、甲壳兽墙 → 蜂巢前哨、进化虫群（★2）；精英：母体巡游、残骸带伏击 |
| Boss | 残骸要塞：不移动，射程覆盖我方前两排，每第 3 次攻击重炮齐射，带护卫和炮巢 |
| 战利品 | 三选一；一半选项是已拥有的舰船（方便合成）；第三个选项有 1/4 概率换成中继信标（最多 6 个）；精英战第一个选项是 ★2 |
| 奖池权重 | 护卫舰、点防御舰、导弹舰、舰载机群各 3，战列舰 1（精英战 3） |
| 剧情 | 出发前雷恩舰长的简报、每个节点的情报简报、通关和失败的结尾对话 |

自动玩家（随机选路线、总选第一个奖励、自动布阵、不用指挥官技能）的通关率约 40%，真实玩家调整布阵并使用技能后应明显更高。

## 5. 布阵与战斗

原型图见 [prototype/Formation2.png](prototype/Formation2.png) 和 [prototype/Battle2.png](prototype/Battle2.png)。

### 5.1 布阵棋盘

- **横向战场**：我方在左、敌方在右，双方前排隔着中间的接触线相对。
- 每一方**前排宽 8 格、纵深 6 格**。小型和中型舰船占 1 格，**大型舰船占 2 × 2 格**。
- 补给节点放在**格子的交叉点**上，不占格子（见第 6 节）。
- 上阵数量受**指挥点上限**限制。
- 布阵可以保存为方案。

| 位置 | 适合 | 原因 |
|---|---|---|
| 前排 | 战列舰、护卫舰 | 先接敌，承受伤害 |
| 后排 | 导弹舰、补给母舰 | 射程远，需要保护 |
| 两翼（前排的上下两端） | 舰载机群、护卫舰 | 速度快，绕后攻击 |

**能否看到敌方阵容**：远征的普通节点和信标链可以看到；少数“未知信号”节点看不到；实时对战看不到（见第 12 节）。

### 5.2 自动战斗

- 舰船按固有的**索敌偏好**自动选目标：舰载机群优先攻击补给节点和远程舰，点防御舰优先攻击舰载机，导弹舰优先攻击重型舰，其余攻击最近的目标。
- 移动到射程内后开火；舰载机在大型舰船之间穿梭，不和它们碰撞。
- 可以 1x / 2x / 4x 观看，或者跳过。
- 时间上限 90 秒，到时比较双方剩余作战单位的耐久。

### 5.3 指挥官技能

每场战斗最多带 3 个，消耗**补给点数**（开局 2 点，每秒 +1，上限 10）：

| 技能 | 消耗 | 冷却 | 效果 |
|---|---|---|---|
| 轨道打击 | 4 | 10 秒 | 选择落点，1 秒后对范围内敌人造成大量伤害 |
| 紧急护盾 | 3 | 15 秒 | 全体恢复一半护盾 |
| （更多技能在远征中获得） | | | 跃迁增援、电磁脉冲、信标过载等 |

### 5.4 威慑

- 开战时比较双方上阵战力；一方超过对方 1.5 倍时，对方进入“被威慑”：射速 −10%。
- 弱势方击毁对方大型舰船时触发“士气爆发”，解除被威慑并短时提高伤害。
- 远征中遇到明显弱于自己的敌人时，可以直接威慑对方投降，跳过战斗并拿到一半奖励。

## 6. 补给网络（核心玩法）

### 6.1 规则

- 兵器占格子；**补给网络在另一层：节点放在格子交叉点上，补给线沿格线走。**
- 每场战斗己方后方有一艘固定的**补给母舰**（大型，占 2 × 2），它前沿中点的交叉点是**补给口**。
- 布阵时可以在交叉点上放**中继信标**，每个消耗 1 指挥点。
- 两个节点在同一条格线上、相距不超过 **3 格**时自动连成补给线。
- 每个节点**覆盖周围 2 格**（以交叉点为中心的 4 × 4 区域）。
- 舰船只要有一格在覆盖范围内，并且这个范围的节点能沿补给线连回补给口，就算**接入补给**。

### 6.2 接入和未接入

| 状态 | 弹药 | 护盾恢复 |
|---|---|---|
| 接入补给 | 持续补充 | 正常 |
| 未接入 | 只有携带的弹药，打完就停火 | 停止 |

- 舰载机群有“短时离网”特性：离开覆盖范围后 10 秒内仍算有补给，适合执行切断任务。

### 6.3 切断

- 战斗中**中继信标可以被摧毁**；被毁后网络重新计算，下游的节点和舰船全部断补给。
- 蜂群也有自己的补给网络（母巢 + 巢链节点），布阵时可以看到，并规划切断路线。

### 6.4 带来的策略

- 阵型紧凑容易覆盖，但怕范围攻击；阵型分散需要更多信标。
- 派舰载机群绕后切断敌方补给，敌方导弹类单位打光弹药就失去威胁。
- 在关键信标附近放点防御舰，挡住来切线的飞蝗群。

已在战斗内核中实现并测试：默认阵型胜率约 27%；把未接入补给的导弹舰挪进覆盖区约 77%；去掉全部中继信标为 0%。

## 7. 战前推演（招牌功能）

- 布阵后点“战前推演”，消耗 1 点情报点，内核在后台用不同随机种子**模拟 100 场**，约 1 秒出结果。
- 结果：**胜率与误差范围、平均用时、平均损失、常见败因、参谋（诺娃）建议、本场推演记录**。
- 限制：
  - 情报点有限（每场 3 点）。
  - 推演不使用指挥官技能。
  - 敌方部分单位有**隐藏特性**，推演按默认值计算，因此有误差；实验室研究可以消除（见第 10 节），商店可以买“侦察”。
  - 真实战斗使用推演中没用过的随机种子。
- 宣传语：“开战之前，你已推演了一百场战争。”

## 8. 舰船体系

### 8.1 晨星舰队舰种

| 舰船 | 定位 | 尺寸 | 克制 | 被克制 |
|---|---|---|---|---|
| 护卫舰 | 轻型，快速 | 1 格 | 远程舰 | 重型舰 |
| 战列舰 | 重型，耐打 | 2 × 2 | 轻型舰、点防御舰 | 舰载机、远程舰 |
| 舰载机群 | 小型机群，机动，可短时离网 | 1 格 | 重型舰、远程舰、补给节点 | 点防御舰 |
| 点防御舰 | 防御舰载机 | 1 格 | 舰载机 | 重型舰 |
| 导弹舰 | 远程火力，弹药有限 | 1 格 | 重型舰 | 轻型舰、舰载机 |
| 补给母舰 | 补给源，无武器 | 2 × 2 | — | — |
| 中继信标 | 补给节点，无武器 | 交叉点 | — | — |

后续扩充：航母（持续放出舰载机）、电子战舰（干扰补给线）、要塞舰、跃迁突击舰，以及逆向得到的蜂群和虚空行者舰船。首发目标：我方约 20 种舰船。

### 8.2 蜂群单位（第一幕）

| 单位 | 定位 |
|---|---|
| 撕裂者 | 轻型，快速近战 |
| 甲壳兽 | 重型，耐打 |
| 飞蝗群 | 小型机群，专切补给线 |
| 酸液炮巢 | 远程，不移动，弹药有限 |
| 母体 | 大型精英，带隐藏特性“重炮齐射” |
| 母巢 / 巢链节点 | 蜂群的补给源和补给节点 |

### 8.3 固有属性与扩展组件

- 每艘舰船有**固有属性**（定位、尺寸、结构值、护盾、伤害、射程、速度、弹药、固有技能、固有特性），决定它的玩法，任何组件都不能改变定位、射程档位和攻击方式。
- 每艘舰船有 **3 个扩展槽**（槽 1 主动、槽 2 和槽 3 被动；槽 2、槽 3 分别在 2 星、3 星解锁），安装远征中获得的组件。
- **双向装配限制**：舰船的槽位规定接受哪些组件类别（武器 / 防御 / 机动 / 支援 / 电子 / 特殊）；组件规定适用哪些舰船（按定位、尺寸、武器类型）。两边都满足才能装。
- 组件只做补充：一艘舰船的战力中，固有属性占 75% 以上，组件不超过 25%。

## 9. 战利品

- 每场战斗胜利后**三选一**：舰船、扩展组件、指挥官技能。
- 精英战和 Boss 必定提供稀有选项。
- 击毁敌人可能掉落**残骸**，带回实验室（第 10 节）。
- 远征结束后：信用点结余转为少量局外货币，用于实验室升级和外观。

## 10. 实验室：缴获与逆向工程

原型图见 [prototype/Lab.png](prototype/Lab.png)。

- 远征中缴获的残骸全部带回母港（失败带回一半）。
- 用残骸在实验室发起**逆向研究**。

**研究时间：现实时间为主，实战缩短为辅**

| 研究对象 | 基础时间 |
|---|---|
| 普通敌人 | 12 小时 |
| 精英敌人 | 18 小时 |
| Boss 武器 | 48 小时 |

- 关闭游戏也会计时；完成后成果一直保留，不会过期。
- **实战缩短随剧情解锁**：

| 阶段 | 解锁时机 | 效果 |
|---|---|---|
| ① | 首次击败残骸要塞：林工带回第一批蜂群样本，实验室开放 | 只有现实时间倒计时 |
| ② | 首次击败吞噬者：实验室接入舰队战斗数据链 | 赢一场战斗 −1 小时，击败 Boss −3 小时，完成一局远征 −2 小时 |
| ③ | 首次击败蜂群主脑：诺娃协助解析，升级为“量子分析中心” | 缩短效果翻倍，研究槽 +1 |

- 额外消耗同类残骸可以加速（每个 −2 小时）。

**研究成果分阶段发放**

| 进度 | 成果 |
|---|---|
| 25% | 揭示该敌人的隐藏特性，以后战前推演对它不再有误差 |
| 60% | 获得它的武器组件图纸，组件加入奖池 |
| 100% | 逆向成功，该敌方舰船加入奖池和图鉴 |

- 研究不会失败。初始 2 个研究槽，最多 4 个。研究树按阵营分支（蜂群科技、虚空科技）。

## 11. 常驻休闲玩法：深空信标链

原型图见 [prototype/Tower.png](prototype/Tower.png)。

### 11.1 设定

星线之外，还有一串通往蜂群领地深处的远古信标，没人知道它通向哪里。舰队沿着这条**深空信标链**一路深入，每打赢一层就点亮一座信标。

- 一层一场战斗，1~2 分钟。**没有体力、没有每日次数、进度永久保留。**

### 11.2 深度区段

| 层 | 区段 | 特点 |
|---|---|---|
| 1~20 | 外围航道 | 教学性质，敌人以轻型、重型为主 |
| 21~40 | 残骸带 | 飞蝗群增多，考验点防御布置 |
| 41~60 | 离子星云 | 电磁干扰规则（补给线连接距离缩短等） |
| 61~80 | 引力深渊 | 引力井、跃迁单位 |
| 81~100 | 蜂巢疆域 | 高难度规则层和 Boss 集中 |
| 101 层以上 | 未知深空（无尽） | 固定种子程序生成，可上排行榜 |

每 10 层：1~8 层普通层（其中 2~3 层带规则），第 9 层精英层，第 10 层 Boss 层兼存档点。

### 11.3 每层的玩法

- **敌方阵容完全公开**，像一道布阵谜题；**失败可无限重试**。
- 每层 2 点情报点，进入新的一层时补满。
- **规则层**（重点考验补给网络）：只能放 1 个中继信标；补给线连接距离降为 2 格；看不到敌方后两排；本层没有补给母舰；中央有引力井；敌方飞蝗群翻倍。

### 11.4 塔内编队与信标模块

- 使用主线和实验室**已解锁**的舰船、组件、指挥官技能，**强度统一**，不受养成数值影响。
- 指挥点上限随深度提升（外围航道 14 点，每个区段 +4）。
- 每过一个 Boss 层，从 3 个**信标模块**中选 1 个长期装上，例如：补给线连接距离 +1、中继信标耐久 +50%、轨道打击冷却 −30%、开局补给点数 +2、舰载机离网时间 +5 秒。最多 6 个，存档点可重新调整。

### 11.5 星级与奖励

- 每层 3 颗星：通关；损失不超过 2 艘；本层特殊条件。
- 首通奖励：信用点、残骸、少量局外货币；每 10 层里程碑奖励称号、涂装、母港装饰。
- **不发放直接提升战力的物品**。
- 可选排行榜：最高层数、总星数，可只看好友。

## 12. 在线玩法（可选）

不联网也能完整游玩全部内容。

| 玩法 | 规则 |
|---|---|
| 玩家阵容节点 | 远征中遇到其他玩家同一幕的真实阵容（异步，主要的在线内容） |
| 排行榜 | 信标链最高层、总星数；每日固定种子的“每日星图”分数（可选，不玩无损失） |
| 天梯（后期） | 上传防守阵容，挑战排名更高的玩家，赢了交换名次；赛季只发外观奖励 |
| 实时对战（后期） | 双方 60 秒盲布阵，三局两胜；服务器用确定性内核计算 |

防作弊：在线玩法的战斗由服务器用同一个确定性内核计算，养成数据以服务器为准。

## 13. 展现方式与美术

- **2D 界面 + 3D 战斗**：母港、星图、商店、实验室、信标链用 2D 界面；布阵和战斗在 3D 场景中。
- **固定镜头**：布阵时接近正俯视；点“开战”后镜头压低，转为从侧前方斜看，舰队从左向右推进。关键时刻自动特写（可关闭）。
- **风格**：低多边形科幻舰船。晨星舰队是棱角分明的蓝白舰体；蜂群是圆润的橙色生物外形；虚空行者紫色。
- **渲染**：URP，HDR 泛光让激光、补给线、信标、爆炸发光；ACES 色调映射、暗角。
- **重点投入**：开火、护盾受击、补给线断开、信标点亮、跃迁、爆炸。
- 舰船只需要移动、转向、开火，不需要骨骼动画，美术成本可控。

## 14. 技术架构

### 14.1 结构

```
Unity 客户端（Starline/Packages/com.starline.game）
├── Runtime/Client     表现层：GameApp 入口、各界面（UI Toolkit）、布阵与战斗控制、3D 舞台
├── Runtime/Resources  配置表（JSON）、界面布局（UXML）与主题（USS）
└── Runtime/Battle     战斗内核（纯 C#，不依赖 Unity）
    ├── Data           配置读取、舰船数据、克制表
    ├── Board          棋盘坐标、布阵规则、补给网络
    ├── Sim            战斗模拟、指挥官技能
    ├── Analysis       战前推演
    ├── Expedition     远征：星图、舰队与合成、奖励、自动布阵
    └── Math           定点数、确定性随机数
```

详细说明见 [client-architecture.md](client-architecture.md)。

### 14.2 关键决策

| 决策 | 理由 |
|---|---|
| 内核与 Unity 分离 | 可以写自动化测试；推演能在后台批量模拟 |
| 定点数 + 固定种子 | 结果在任何电脑上一致：推演、回放、在线对战都依赖它 |
| 数据驱动 | 舰船、敌人、技能、星图、奖池、剧情文本都在 JSON 配置表里，内核和测试读同一份 |
| 本地存档 + Steam 云存档 | 换电脑可继续 |

### 14.3 仓库结构

```
XFramework/（仓库）
├── Starline/                         Unity 工程
│   └── Packages/com.starline.game/   游戏代码
├── src/Starline.Battle/              用 .NET 编译战斗内核
├── tests/Starline.Battle.Tests/      内核测试与平衡性模拟
└── docs/                             设计文档与原型图
```
