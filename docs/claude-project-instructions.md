## 项目是什么

Starline 是一款单机科幻战略游戏，Steam 买断制，用团结引擎 1.10.4（基于 Unity 2022.3）+ URP 开发。
- 世界观：蜂群切断了连接人类殖民地的超空间航线“星线”，玩家指挥晨星舰队一段段把它重新点亮。
- 核心玩法：Roguelite 远征（三幕，每局 25~30 分钟）；横向布阵（每方前排 8 格、纵深 6 格，大型舰船占 2×2）后自动战斗，保留 3 个指挥官技能。
- 创新点：补给网络（中继信标放在格子交叉点，连线 ≤ 3 格、覆盖 2 格，断补给的舰船弹药打完就停火）和战前推演（开战前模拟 100 场，给出胜率和败因）。
- 其他模块：实验室（缴获敌方残骸做逆向研究，现实时间计时）、常驻休闲玩法“深空信标链”（爬塔）。
