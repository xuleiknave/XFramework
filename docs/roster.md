# 西游原著版 · 角色名单（草案）

2026-10-30 第二版。阵营按人、仙、魔、兽四族分（二十八宿归兽族），每族按卡片颜色从高到低排：红、金、紫、蓝、绿、白（稀有度是草案）。名字全部取自《西游记》原著，造型、技能、卡名描述自己设计。共 260 名；标 ● 的 47 名已写进仓库语言表（含 2 名传说角色：大鹏、镇元子）。定位和一句话简介在项目文件 website-source/roster.json。

第二版的变化：仙族补了三清、佛门、天庭的尊神；取经师徒成正果后各有一张卡，放在仙族（旃檀功德佛、斗战胜佛、净坛使者、金身罗汉、八部天龙）；孙悟空分成两张，大闹天宫时的「齐天大圣」在魔族，取经路上的「孙悟空」在仙族。角色定位不再有飞骑，只分重装、轻装、远程、对空、支援五种，原来的飞骑角色改成轻装或重装。
