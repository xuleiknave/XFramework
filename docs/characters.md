# 角色小传

> v6.0（决策 77）：全部换成《西游记》原著人物。这里是先写进语言表的 45 名角色加 2 名传说角色，每人 5 段小传：★1 招募时可看，★2~★5 逐段解锁，★5 那段也是通关尾声里的个人结局。完整名单 232 名见 [roster.md](roster.md)。

> 小传只用原著的情节和人物关系，个人的心里话（每人第 5 段的“他说……”）是游戏补写的。正文和 `Localization/Characters.csv` 的 bio.<id>.1~5 一致，改的时候两边一起改。

## 人族

### 唐僧 · 取经人

支援 · id `eileen`

1. 东土大唐的高僧，奉旨往西天取经，法名玄奘，号三藏。
2. 他出生时家里遭了大难，被母亲放在木板上顺江漂走，被金山寺的长老救起，在寺里长大。
3. 他手无缚鸡之力，一路上被妖怪捉走的次数数不清，却从没说过一句往回走。
4. 他念的紧箍咒让悟空头疼，可每回把悟空赶走，他夜里都睡不着。
5. 他说，取经路上的每一难都是要过的。徒弟们挡在前面，他就在后面念经，替他们挡住那些看不见的东西。

### 刘伯钦 · 镇山太保

轻装 · id `cedric`

1. 双叉岭的猎户，人称镇山太保，一柄钢叉打得猛虎不敢近身。
2. 唐僧刚出长安，在双叉岭遇上了猛虎，是刘伯钦提着钢叉赶来救了他。
3. 他把唐僧请回家吃了一顿素斋，又一路送他翻过双叉岭，送到两界山下。
4. 他父亲刚去世不久，唐僧替老人家念了一夜经。那晚全家都梦见老人说，自己已经超生了。
5. 到了两界山，他说那边就不是大唐的地界了，不敢再往前送。山脚下传来一声大喊：“师父来了！”那是被压了五百年的悟空。

### 秦叔宝 · 守门将

重装 · id `rayne`

1. 大唐的开国大将，使一对熟铜锏，和尉迟恭一起替太宗守过宫门。
2. 泾河龙王的魂夜夜来闹，他说自己一辈子在阵前，不怕什么鬼祟，愿和尉迟恭一起守夜。
3. 两人守了好几夜，宫里终于安静了。太宗怕他们辛苦，叫画工画下了他们的像。
4. 前门安了，后门又闹，最后是魏征提着宝剑守住了后门。秦叔宝说，门总得有人守。
5. 他说，守门这件事没有尽头。只要屋里还有人睡着，门口就得有人站着。

### 尉迟恭 · 门神

对空 · id `harold`

1. 大唐的开国大将，黑脸，使一条钢鞭。
2. 泾河龙王被斩之后，夜夜到宫里来闹，太宗不得安宁。
3. 尉迟恭和秦叔宝披挂整齐，在宫门外守了一夜又一夜，宫里就再没闹过。
4. 后来太宗叫画工把两人的模样画下来贴在宫门上，人间从此家家户户贴门神。
5. 他说，他不会飞，也不会变，只会守门。可只要他站在那里，谁也别想从这里过去。

### 魏征 · 大唐丞相

轻装 · id `thorne`

1. 大唐的丞相，敢当面直谏，太宗都让他三分。
2. 泾河龙王犯了天条，玉帝降旨，命魏征在午时三刻监斩。
3. 那天太宗故意拉他下棋拖住他，他下着下着伏在案上睡着了，在梦里斩了龙王。
4. 龙王的魂怪太宗没救他，夜夜来闹。前门有秦叔宝、尉迟恭守着，后门是魏征提着宝剑守住的。
5. 他说，他这辈子只做了两件事：说该说的话，守该守的门。

### 袁守诚 · 算卦先生

支援 · id `celine`

1. 长安西门大街上的算卦先生，卦算得极准。
2. 渔翁张稍每天送他一尾金色鲤鱼，他就告诉张稍在哪里下网，一网一个准。
3. 泾河龙王变成白衣秀士来砸他的招牌，问明天几时下雨、下多少，他张口就报了出来。
4. 龙王为了赢他，私改了雨数，犯了天条。龙王回来找他算账，他说：你的命，只有大唐的人皇救得了。
5. 他说，卦是准的，可人总想改卦。改得了天上的雨，改不了自己的命。

### 乌鸡国太子 · 小储君

远程 · id `zane`

1. 乌鸡国的太子，只觉得这三年来，父王对母后冷淡了许多。
2. 他出城打猎，追一只白兔一路追到了宝林寺，那只白兔是悟空变的。
3. 唐僧拿出父王托梦留下的白玉圭，太子才知道，宫里坐着的是个假国王，真的父王被推在井里已经三年了。
4. 他回宫偷偷问母后，母后说，三年前的父王是暖的，这三年，那个人冷得像冰。
5. 父王救活以后，太子站在他身边。他说，这三年他什么都没看出来，是他这辈子最后悔的事。

### 女儿国王 · 西梁女王

支援 · id `mona`

1. 西梁女国的国王，国中全是女子。
2. 唐僧师徒来换通关文牒，她一见唐僧，就想留他做国王，自己做王后。
3. 她把一国的富贵都摆在唐僧面前，唐僧只是低着头念经。
4. 悟空出了个主意，让师父假意答应，等文牒盖了印再走。她亲自送师徒出了城。
5. 唐僧上马的那一刻，她才明白过来。她没有追，只是在城门口站了很久。

### 渔翁张稍 · 泾河渔翁

远程 · id `anvil`

1. 泾河岸边的渔翁，每天在河上撒网。
2. 他每天送给长安城的袁守诚先生一尾金色鲤鱼，先生告诉他在哪里下网，一网一个准。
3. 他和樵夫李定在河边喝酒对诗，一个夸水好，一个夸山好，谁也不让谁。
4. 他把袁先生的卦说给李定听，被巡水的夜叉听了去，报给了泾河龙王。
5. 后来的一大串事，都是从他这一句话起的。他说，他只是个打鱼的，嘴快了一点。

### 樵夫李定 · 泾河樵子

重装 · id `kalan`

1. 泾河岸边的樵夫，每天上山砍柴，下山卖柴。
2. 他和渔翁张稍是老朋友，常在河边对诗，一个说山好，一个说水好。
3. 他听张稍夸袁先生的卦，劝他：小心些，河里也有耳朵。
4. 果然，河里的夜叉听见了，泾河龙王就此找上了袁守诚。
5. 他说，砍柴的人最懂，树倒之前都是有声音的，只是没人听。

### 陈光蕊 · 新科状元

支援 · id `alder`

1. 海州的书生，考中了状元，娶了殷丞相的女儿殷温娇。
2. 他带着妻子去江州赴任，渡江时被船家推进了江里，船家冒了他的名去做官。
3. 赴任路上，他在洪江口买下一尾金色鲤鱼放了生，那条鱼是洪江的龙王。
4. 龙王把他的身子和魂魄留在了水府，一留就是十八年。
5. 十八年后，儿子玄奘替父母报了仇，龙王把他送回人间。他睁开眼，看见的是已经长大的儿子。

## 仙族

### 猪八戒 · 天蓬元帅

重装 · id `gavin`

1. 原是天河里的天蓬元帅，醉后调戏了嫦娥，被贬下界，错投了猪胎。
2. 他在福陵山云栈洞落脚，后来到高老庄招了亲。干活一个顶仨，吃饭也一个顶仨。
3. 观音给他起了法名悟能，唐僧又叫他八戒。他嘴上总嚷着散伙回高老庄，钉耙却从没离过手。
4. 他最爱在师父面前告大师兄的状，可大师兄被妖怪拿住时，第一个急红了眼的也是他。
5. 九齿钉耙是太上老君亲手锻的神兵。八戒说，这把耙子能筑山，能筑妖，也能给师父筑出一条路来。

### 沙悟净 · 卷帘大将

重装 · id `bran`

1. 原是灵霄殿下的卷帘大将，在蟠桃会上失手打碎了玻璃盏，被贬到了流沙河。
2. 他在流沙河里熬了很多年，每七天就要受一次飞剑穿胸之苦。
3. 观音点化了他，叫他在河里等取经人。他等了很久，等来的就是唐僧。
4. 他话最少，担子最重。大师兄去降妖，二师兄去化斋，守着师父和行李的总是他。
5. 他的降妖宝杖是月宫梭罗仙木做的。他说，这根杖子当年卷过帘，现在只想替师父挡住风沙。

### 孙悟空 · 齐天大圣

轻装 · id `cassie`

1. 东胜神洲花果山上一块仙石里蹦出来的石猴，领着群猴进了水帘洞，被尊为美猴王。
2. 他漂洋过海拜菩提祖师学艺，学会了七十二变，和一个跟头十万八千里的筋斗云。
3. 他闯东海龙宫取走了定海神针，到地府勾了生死簿，被天庭招安做了弼马温，嫌官小，自封齐天大圣。
4. 他偷蟠桃、盗御酒、吃仙丹，大闹天宫，最后被压在五行山下五百年。
5. 唐僧揭下山顶的帖子放他出来，他拜了师父，戴上金箍，一路降妖往西走。火眼金睛看得穿妖怪，却常看不懂师父的心。

### 哪吒 · 三太子

飞骑 · id `roland`

1. 托塔天王李靖的三太子，三头六臂，脚踏风火轮，是天庭有名的少年战将。
2. 大闹天宫时，他和悟空大战，六件兵器变成千千万万，还是没赢下那只猴子。
3. 后来悟空保唐僧西行，打不过妖怪就上天搬救兵，哪吒是来得最痛快的一个。
4. 他和悟空打出了交情。悟空说，满天神将里，就数这位三太子打得最爽快。
5. 他和父亲之间有一段不好说的旧事，父亲手里那座宝塔就是因他而有的。他不爱提，只说现在和父亲并肩出战挺好。

### 二郎神 · 显圣真君

轻装 · id `nightingale`

1. 灌江口的显圣二郎真君，玉帝的外甥，额上生着天眼，手持三尖两刃刀。
2. 他听调不听宣，平日住在灌江口，带着梅山六兄弟和一千二百草头神。
3. 大闹天宫时，十万天兵拿不下悟空，是他来了。他和悟空斗变化，从花果山一路斗到了灌江口。
4. 最后太上老君丢下金刚琢打中了悟空，他的细犬一口咬住悟空的腿，才把大圣拿住。
5. 他说，那一仗不算他一个人赢的。后来西行路上悟空来求他帮忙，他二话没说就来了：打过的对手，才最信得过。

### 李靖 · 托塔天王

支援 · id `beth`

1. 天庭掌管天兵的托塔天王，手里托着一座玲珑宝塔。
2. 大闹天宫时，他奉旨领兵围剿花果山，巨灵神和哪吒都是他派出去的。
3. 他手里的宝塔能镇住一切，就连三太子也要让这座塔三分。
4. 西行路上，有个老鼠精自称是他的义女。悟空上天告了他一状，他这才想起三百年前收过这么一个女儿。
5. 他说，带兵的人最怕的不是打输，是忘了自己手下还有谁。

### 太白金星 · 长庚星

支援 · id `wheat`

1. 天庭里最和气的老神仙，长庚星。
2. 悟空在花果山称王时，是他劝玉帝招安，亲自下界请悟空上天做官。
3. 悟空嫌弼马温官小，反下天去，又是他出主意，封了一个“齐天大圣”的名号。
4. 唐僧刚出长安就在双叉岭落了难，是他化作老人，把唐僧领出了妖洞。
5. 他说，打架的事交给年轻人，他只管让大家少打几架。

### 千里眼 · 天庭耳目

远程 · id `john`

1. 天庭的耳目，能看见千里之外，常和顺风耳一起守在南天门。
2. 石猴出世时目运金光，射冲斗府，他奉旨开了南天门去看，第一个看见了悟空。
3. 他看得见云下的山川河流，也看得见哪里冒起了妖气。
4. 西行路上的妖怪，好些是从天上偷跑下去的。他看得清清楚楚，只是没人问，他也不说。
5. 他说，看得远是本事，看得准才是功夫。

### 顺风耳 · 天庭耳目

远程 · id `grey`

1. 天庭的耳目，能听见千里之外的声音，常和千里眼一起守在南天门。
2. 石猴出世那天，两道金光射冲斗府，玉帝就是派他和千里眼去查看的。
3. 他听见花果山的猴子们在欢呼，回去报说那只是天地精华生出的一只石猴，不足为奇。
4. 后来那只石猴大闹天宫，他想起自己说过的话，好几百年都没敢再提。
5. 他说，听得见不等于听得懂。

### 雷公 · 雷部

远程 · id `duke`

1. 雷部的雷神，一手持锤，一手持楔，一锤下去天雷滚滚。
2. 车迟国斗法求雨时，悟空在半空拦住了他，叫他等道士作完法再动手。
3. 悟空的棒子往下一指，他的雷就响了，那一场雨下得满城欢喜。
4. 他和电母向来一起出手，电光照到哪里，他的雷就打到哪里。
5. 他说，雷不能乱打，打对了地方，才叫天雷。

### 电母 · 雷部

对空 · id `marta`

1. 雷部的电神，雷公打雷之前，先由她放出电光照亮目标。
2. 车迟国斗法求雨时，风婆婆、雷公、电母都被悟空拦在半空，不许帮那几个道士。
3. 悟空的棒子一举，她就放电；棒子一落，雨就下来了。那一场雨，是替取经人下的。
4. 她和雷公向来一起出手，一个照，一个打，从没失过手。
5. 她说，电光照得见云下的一切，照不见人心，所以她只照该照的地方。

### 值日功曹 · 四值功曹

支援 · id `olivia`

1. 四值功曹之一，管一天里的事，奉命暗中护送唐僧西行。
2. 他常变成老人或樵夫，在路口给师徒报信：前面有妖怪，小心些。
3. 悟空嫌他们报得慢，常拿棒子吓唬人。他也不恼，下一回照样来报。
4. 每天轮班交接，他都要把师徒这一天的平安记下来，一层层往上报。
5. 他说，护法是师徒看不见的那一层。取经的人在前面走，他们就在后面跟着，九九八十一难，一难也不能少。

## 魔族

### 混世魔王 · 水脏洞主

轻装 · id `greyclaw`

1. 坎源山水脏洞的魔王，趁美猴王出海学艺，霸占了水帘洞，抢走了不少小猴。
2. 他使一口大刀，在花果山一带横行。
3. 悟空学艺回来，听说家被占了，一个筋斗就翻到了他的洞前。
4. 这是悟空回山后打的第一仗，他拔下毫毛变出几百只小猴，把魔王围在了中间。
5. 他是第一个让悟空知道自己学成了的妖怪。妖王寨里谁都不服他，可谁也没法说他不是第一个。

### 黑熊精 · 黑风大王

重装 · id `big_tom`

1. 黑风山黑风洞的妖王，一身黑毛，使一杆黑缨枪。
2. 观音院起火那一夜，他趁乱偷走了唐僧的锦襕袈裟，要开一个“佛衣会”。
3. 他和悟空打得难分难解，还有凌虚子、白衣秀士两位朋友帮衬。
4. 观音菩萨收了他，给他戴上一个禁箍，叫他做了落伽山的守山大神。
5. 他说，偷袈裟只是因为那件衣裳太好看了。后来守了山，他每天都能看见比那好看得多的东西。

### 蜘蛛精 · 盘丝七姐妹

远程 · id `whisper`

1. 盘丝岭盘丝洞的七个蜘蛛精，是七姐妹。
2. 她们腰间能吐出丝绳，一会儿就把整座庄院罩成了天棚。
3. 唐僧独自去化斋，被她们用丝绳绑进了洞里。
4. 她们和黄花观的百眼魔君是师兄妹，打不过悟空，就去找师兄。
5. 七姐妹说，她们本来只想在山里过自己的日子，可取经人偏偏走到了她们门口。

### 百眼魔君 · 蜈蚣精

远程 · id `venomeye`

1. 黄花观的道士，本是一条修成人形的蜈蚣精，号多目怪。
2. 他用毒枣泡茶，唐僧、八戒、沙僧喝下去就倒了。
3. 他脱下衣裳，两肋下一千只眼睛放出金光，把悟空罩在里面。
4. 毗蓝婆菩萨用一根绣花针破了他的金光，他现出了原形。
5. 他说，他有一千只眼睛，却只看得见自己的师妹们。

### 牛魔王 · 平天大圣

重装 · id `mog`

1. 积雷山摩云洞的平天大圣，力大无穷，使一条混铁棍。
2. 当年悟空在花果山称王时，和他结拜成七兄弟，牛魔王是大哥。
3. 他的儿子红孩儿被观音收去做了善财童子，这笔账他一直记着。
